# 製品要求一覧(REQ)

版: 0.1 / 2026-11-13。範囲: **初期版** / 後続 / 対象外。各要求は設計箇所(製品仕様・操作契約・データ契約の節)と検証項目(`VER-…`、[verification-plan.md](verification-plan.md))に結び付く。検証IDは要求IDと同じ枝番(`REQ-F-001` ↔ `VER-F-001`)。
判断の根拠は [plans/decisions.md](../../plans/decisions.md)(`DEC-…`/`OPEN-…`)、モジュール挙動は [specifications/modules/](../modules/README.md)(`MOD-…`/`COM-…`)、調査事実は [references/](../../references/index.md)(`F-…`)。

## エージェント操作要求(REQ-A)
| ID | 要求 | 範囲 | 根拠 | 設計箇所 | 受入判定方法 |
