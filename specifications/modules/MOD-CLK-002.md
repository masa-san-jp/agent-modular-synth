# MOD-CLK-002 クロック分周

## 1. 目的と範囲
- 目的: 入力クロックの立ち上がりを数え、1/2, 1/4, 1/8, 1/16, 1/32, 1/64 の固定分周出力と、1/N(N=2〜64)の可変分周出力1つを、デューティ約50%のゲートとして出力する。RESET入力がhighの間は全出力を0にして計数を先頭へ戻す。
- 含む: 立ち上がり計数、7つの出力、可変分周 `division`、RESET(レベル)、リセット後1 msのCLOCK無視、状態保存。
- 含まない: 逓倍(倍化。後続)、パルス出力モード、分周比のCV変調、位相オフセット、ユークリッド分配、スウィング。

## 4. パラメータ
| 名前 | 単位 | 範囲 | 既定値 | 変調 | 更新タイミング | 補間 |
|---|---|---|---|---|---|---|
| division | クロック数(整数、1/N の N) | 2〜64(最近接整数へ四捨五入、0.5は切り上げ、その後クランプ。COM-13。NaN/∞は既定3) | 3 | なし(CV入力ポートを持たない) | 次のステップ。変更時に out_div のカウンタを `c = c mod N_new` に折り返す。出力の値はすぐには変えず、次のクロックで新しい分周比に従う | なし |

固定出力の分周比 {2, 4, 8, 16, 32, 64} は定数でパラメータ化しない。パラメータ `division` のNaN/∞は**既定値(3)**として扱い、有限の範囲外値は四捨五入後にクランプする(COM-12/13。例: `division=+∞` は64でなく3、`division=100` は64)。CV入力ポートを持たないため、CV感度(COM-18)はない。

## 5. 内部状態と初期化・リセット
- 状態変数: `cs`: clockのシュミット状態(0/1)、初期値0。`rs`: resetのシュミット状態、初期値0。`c[i]`(i=0〜6): 各出力のカウンタ(整数)、初期値 `N_i − 1`(次のクロックで0になる)。`hi[i]`: 各出力の現在値(0/1)、初期値0。`guard`: リセット後のCLOCK無視の残りサンプル数、初期値0。ここで `N = [2,4,8,16,32,64, division]`。
- `reset()`: 全状態を初期値に戻す。パラメータは変えない。
- リセットの種類(COM-10): `reset()` は**全体リセット**、RESET入力は**音楽的リセット(レベル型)**で、highの間は**全出力を0**にして計数を先頭へ戻し、lowへ戻ったステップから `ceil(0.001·fs)` サンプルCLOCKを無視する(COM-07のレベル型RESET)。
- RESET入力(音楽的リセット・レベル型): `reset` がhighの間、毎ステップ `c[i]=N_i−1, hi[i]=0, guard=ceil(0.001·fs)` とし、CLOCKの立ち上がりは無視する(ただしclockのシュミット状態は更新される)。

## 6. 振る舞い
`fs` はサンプルレート。入力のNaN/∞は0 Vとして扱う(COM-12)。
```
div_p = finite(division) ? division : 3                       // パラメータのNaN/∞は既定値(COM-12)
N = [2, 4, 8, 16, 32, 64, clamp(round(div_p), 2, 64)]          // 四捨五入(0.5切り上げ)→クランプ(COM-13)
(cp, cs) = schmitt(clock, cs);  edge = (cp==0 && cs==1)
(rp, rs) = schmitt(reset, rs)
for i in 0..6: if c[i] >= N[i]: c[i] = c[i] mod N[i]          // division変更時の折り返し

if rs == 1:                                    // COM-07: RESETが最優先(レベル)
    for i: c[i] = N[i]-1;  hi[i] = 0
    guard = ceil(0.001*fs)
elif guard > 0:
    guard -= 1                                 // リセット解除後の1 msはCLOCKを無視
elif edge:
    for i: c[i] = (c[i] + 1) mod N[i]
           hi[i] = (c[i] < ceil(N[i]/2)) ? 1 : 0

out[i] = 10 * hi[i]                            // 出力 out2..out64, out_div
```
- 最初のクロック(リセット後または初期状態)で全 `c[i]=0` となり全出力がhighに立ち上がる(S-09)。以降、出力 `i` は N_i クロックで1周期、最初の ceil(N_i/2) クロックの間high。
- 出力はクロックの立ち上がりを数えた値を保持するだけで、入力クロックの幅には依存しない。入力クロックがhighのまま(立ち上がりなし)でも出力は変わらない。
- サンプルレート依存: リセット後の無視区間のみ `ceil(0.001·fs)` サンプル(fs=48000で48、44100で45)。それ以外は `fs` に依存しない。
- 出力の書き込みは当該ステップ末で、次のステップに接続先が読む(COM-06)。クロックの立ち上がりと同じステップで出力が変化する(モジュール内の遅延なし)。

## 7. 共通規約との関係
- COM-04: clock/resetのシュミット閾値(ON 2.0 V, OFF 0.1 V)。生成側はgate high=10 V。
- COM-05/06: 1サンプル処理、出力は次ステップで接続先が読む。
- COM-07: 処理順は RESET(レベル)→ CLOCK計数。同一ステップで reset の立ち上がりと clock の立ち上がりが重なった場合、reset が優先されclockは数えない。COM-07の「RESET後1 ms無視」を採用する(S-08)。
- COM-09: 未接続のclock/resetは0 V。
- COM-12: 出力がNaN/∞になる経路はない。
- COM-10: リセットの種類は §5(`reset()`=全体、RESET入力=音楽的・レベル型)。
- COM-12: パラメータ `division` のNaN/∞は既定値3。入力のNaN/∞は0 V。
- COM-13: `division` は四捨五入→クランプ、補間なし。
- COM-14: 保存対象は §9。

## 8. 異常入力・境界・数値安定性
- clockのNaN/∞は0 V(エッジなし、TV-08)。resetのNaNは0 V(リセットなし)。
- シュミット: clockが2.0 V未満から0.1 Vより大きい値の間に留まる信号は再トリガしない(ヒステリシス、TV-07)。
- `division` が範囲外: 1→2、100→64、2.5→3(四捨五入、0.5は切り上げ)。NaN/±∞は既定3(TV-04)。
- clockがhighのまま: 立ち上がりが1回だけ数えられる(TV-06)。
- 出力は常に0か10 V。カウンタは [0, N) に保たれ、オーバーフローしない(division変更時は折り返し、TV-05)。
- 音質の要件は本仕様の対象外。機能再現(出力位相・分周)のみを検証する。

## 9. 保存・復元・版互換
- 保存対象: パラメータ(division)、内部状態(`cs`, `rs`, `c[0..6]`, `hi[0..6]`, `guard`)、`spec_id=MOD-CLK-002` と仕様版 `0.1`。乱数は使わない。
- 復元の同値性: 同じ入力列に対しビット同一の出力列を返す(TV-13)。
- 版移行: 初版のため旧版はない。固定出力の追加は後続の版とし、既存の出力順序(out2, out4, …, out64, out_div)を保つ。

## 11. 未確認・保留事項
- 原機(A-160-1)の出力ごとの分周比、出力波形のデューティ(50%か短いパルスか)、リセット解除後の最初のクロックの扱いは資料にない。S-06, S-07, S-09は[A]で、#3で原機寄せの別モード(パルス出力、A-160-1の対応表)を入れるか判断する。
- 逓倍(倍化)は後続。PPQN相当の位相ロック付き逓倍はMOD-CLK-001のティック生成との接続で検討する。
- 「RESET後1 ms無視」の解釈(S-08)は[A]。VCV Rack側の定義(RESETトリガ後)との差を#3で確認する。
- ポリフォニー時の `division` の共有・チャンネル別は未定義(モノを正本)。
