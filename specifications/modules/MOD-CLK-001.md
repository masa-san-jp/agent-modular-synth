# MOD-CLK-001 クロック

## 1. 目的と範囲
- 目的: テンポ(BPM)から周期的なクロックパルス(`clock`、1 ms幅)とゲート(`gate`、デューティ可変)を生成する。RUNで開始/停止し、RESETで位相を先頭へ戻す。テンポは1 V/oct のCVで変調できる。
- 含む: BPM、1拍あたりのティック数(`ppqn`)、スウィング、ゲートのデューティ、run、RUN/RESET/BPM CV入力、リセット、状態保存。
- 含まない: 外部クロック同期(MIDIクロック、DIN Sync)、テンポの滑らかな遷移(補間)、ラチェット/バースト、ソング位置(SPP)、複数出力の分周(MOD-CLK-002が担当)。

## 4. パラメータ

|---|---|---|---|---|---|---|

| ppqn | ティック/拍(整数) | 1〜96(四捨五入して整数化、範囲外はクランプ) | 1 | なし | 次のステップ | なし |
| swing | 周期の倍率 | 0〜0.5(クランプ) | 0 | なし | 次のステップ | なし |

## 5. 内部状態と初期化・リセット
- 状態変数: `phase`: 倍精度実数、初期値 1.0(「ティックが今来る」)。`k`: 整数(次のティックの通し番号。リセットから数える)、初期値0。`pending`: 整数(スウィングで遅延中の残りサンプル数)、初期値0。`pulse`: 整数(clockパルスの残りサンプル数)、初期値0。`gate_rem`: 整数(gateの残りサンプル数)、初期値0。`rs`, `us`: reset/runのシュミット状態、初期値0。
- `reset()`(COM-10): 上記の全状態を初期値へ戻す。パラメータは変えない。
- RESET入力(音楽的リセット): 立ち上がりで `phase=1.0, k=0, pending=0` とし、同一ステップでティックを発生させる。`pulse`/`gate_rem` は新しいティックで更新される(出力中のパルスは延長/再開、不連続な出力は出さない)。

## 6. 振る舞い
`fs` はサンプルレート。入力のNaN/∞は0 Vとして扱う(COM-12)。
```
(rp, rs) = schmitt(reset, rs);  rising_reset = (rp==0 && rs==1)
run_gate = (run 未接続) ? 1 : schmitt(run, us)
running  = (param.run >= 0.5) && run_gate
bpm_eff  = clamp(clamp(bpm,20,1000) * 2^clamp(bpm_cv,-10,10), 20, 1000)
ppqn_i   = clamp(round(ppqn), 1, 96)
dphi     = min(0.5, bpm_eff*ppqn_i / (60*fs))        // 1サンプルあたりのティック数
P        = 1/dphi                                      // ティック周期(サンプル、実数)
fire     = false

if !running:
    phase = 1.0; k = 0; pending = 0; pulse = 0; gate_rem = 0     // 停止中は出力0、再開で先頭から
else:
    if rising_reset:  phase = 1.0; k = 0; pending = 0            // COM-07: RESETが最初
    if pending > 0:
        pending -= 1
        if pending == 0: fire = true                             // スウィング遅延の満了
    if phase >= 1 - 1e-9:                                        // 位相がティック境界に到達
        phase -= 1;  kc = k;  k += 1
        if (kc is odd) && swing > 0:  pending = max(1, round(swing*P))
        else:                          fire = true
    phase += dphi
    if fire:
        pulse    = min( max(1, round(0.001*fs)), max(1, floor(P/2)) )
        gate_rem = max(1, round(duty*P))

clock = (pulse > 0)    ? 10 : 0
gate  = (gate_rem > 0) ? 10 : 0
if pulse > 0:    pulse -= 1
if gate_rem > 0: gate_rem -= 1
```
ここで `round(x)=floor(x+0.5)`。
- 出力は当該ステップに書き、次のステップに接続先が読む(COM-06)。ティックを発生させたステップ `n` で `clock` は10 Vとなり、`pulse` サンプル(既定 round(0.001·fs) = fs=48000で48)だけ続く。
- サンプルレート依存: `dphi = bpm_eff·ppqn/(60·fs)`、パルス幅 `round(0.001·fs)` サンプル(1 ms)。`phase` は倍精度で保持する(境界判定の許容 1e-9 は倍精度の累積誤差 〜1e-12 より十分大きい)。ティックの位置は非整数周期でも平均周期が正確に `P` となる(最大±1サンプルの量子化)。
- ティックが1ステップに2回以上来ないよう `dphi` を0.5以下にクランプする(最大ティックレート fs/2)。パルス幅は周期の半分(切り捨て)以下に制限し、連続high化を防ぐ。
- `gate` は新しいティックで `gate_rem` を上書き再開(加算しない)。スウィングで次のティックまでの距離が `duty·P` より短い場合、`gate` は連続してhighとなる。
- 最初のティックは、リセット後/run開始後の最初の running ステップ(`phase=1.0` のため)に出る。

## 7. 共通規約との関係
- COM-03: BPMの基準は120 BPM(2 Hz)。`bpm_cv` は1 V/oct(`bpm_eff = bpm·2^cv`)。
- COM-04: reset/runのシュミット閾値(ON 2.0 V, OFF 0.1 V)。生成側はtrigger/clock=10 V・1 ms、gate=10 V。
- COM-05/06: 1サンプル処理。出力は次ステップに現れる。
- COM-07: 処理順は RESET → ティック判定。「RESET後1 ms無視」の採用は不要(CLOCK入力を持たない)。
- COM-09: 未接続のrunは `normal=10 V`。
- COM-12: 出力がNaN/∞になる経路はない。
- COM-13: bpm_cvの感度は1 oct/V、クランプ −10〜+10 V。
- COM-14: 保存対象は §9。倍精度の `phase` を精度を保って保存する。

## 8. 異常入力・境界・数値安定性
- `bpm` が範囲外: 20〜1000へクランプ(TV-06)。`bpm_cv` のNaN/∞は0 V(TV-09)。
- `ppqn=0` は1、`ppqn=2.6` は3に丸める(TV-09)。`duty=0` は0.01、`swing=0.9` は0.5(TV-08, TV-09)。
- fsが低くティックレートがfs/2を超える場合は `dphi=0.5`(2サンプルに1ティック、TV-06)。
- run入力がhighでも `param.run=0` なら停止。run入力がlow(接続時)でも停止(TV-10)。
- 長時間運転: 倍精度の位相の誤差は 1e-9 秒オーダーで蓄積しない(ティック毎に整数1を引くため位相は [0,1) に保たれる)。
- 音質の要件は本仕様の対象外(パルスのエッジ品質の問題はない)。機能再現(ティック位置・パルス幅)のみを検証する。

## 9. 保存・復元・版互換
- 保存対象: パラメータ5つ(bpm, ppqn, swing, duty, run)、内部状態(`phase`, `k`, `pending`, `pulse`, `gate_rem`, `rs`, `us`)、`spec_id=MOD-CLK-001` と仕様版 `0.1`。乱数は使わない。
- 復元の同値性: 同じ入力列に対しビット同一の出力列を返す(TV-13)。`phase` は倍精度のまま保存する。
- 版移行: 初版のため旧版はない。

## 11. 未確認・保留事項
- 外部クロック同期(MIDIクロック24 ppqn、DIN Sync)、テンポの滑らかな遷移、ラチェットは含めていない。#3/後続で扱う。
- スウィングの定義(奇数ティックを遅らせる方式)とその範囲は[A]。原機の定義は資料にない(F-003-018 は存在のみ)。
- RUN停止中の出力・再開位置(先頭へ戻す方式)、RESET同時入力の優先順、最大クロックは原機(M006)の資料にない。S-10/S-08は[A]。#3で「停止位置から再開」を選ぶか判断する。
- `bpm` を実数にしたのは[A]である(F-018-025は整数)。UIの粒度は#3。
- 位相累積器は倍精度を要求する。実装が単精度の場合の許容は定めていない(#3で実装方針を決める際に再検証)。
