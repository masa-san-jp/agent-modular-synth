# MOD-FLT-001 ローパスフィルタ(ラダー系)

## 1. 目的と範囲
- 目的: 音声入力 `in` を、4段縦続の1極ローパス(-24 dB/oct)に出力段フィードバック(レゾナンス)を掛けたフィルタで処理する。カットオフは手動値と3系統のCVの和で1 V/octに制御する。1サンプルごとに「入力と制御値を読む→係数を計算→4段の状態を更新→出力」を行う。
- 含む: カットオフ(手動+CV1〜3の加算)、レゾナンス(手動+CV)、自己発振(レゾナンスを上げた状態で入力なしに正弦波が持続)、サンプルレート依存の係数計算。
- 含まない: ハイパス/多モード/SVF(カタログ上は後続)、ドライブ(入力飽和)、トランジスタ回路の非線形・温度ドリフト・実機の周波数トラッキング誤差の再現、オーバーサンプリング。原機の音響再現は保証しない。

## 4. パラメータ
| 名前 | 単位 | 範囲 | 既定値 | 変調 | 更新タイミング | 補間 |
|---|---|---|---|---|---|---|
| cutoff | V(C4=0 Vからのオクターブ数) | -5〜+6(範囲外はクランプ) | 3.0(約2093 Hz) | 可: `cv1`(感度1)、`cv2`(感度`cv2_level`)、`cv3`(感度`cv3_level`)を加算 | 次のステップ | なし(階段状) |
| res | 無次元 | 0〜1 | 0.0 | 可: `res_cv`(感度0.1/V)。有効値は0〜1でクランプ | 次のステップ | なし |
| cv2_level | 無次元 | -1〜+1 | 1.0 | 不可 | 次のステップ | なし |
| cv3_level | 無次元 | -1〜+1 | 1.0 | 不可 | 次のステップ | なし |

- パラメータにNaNが来たら、そのパラメータの既定値を使う(COM-13のクランプでは定まらないため)。[A]
- 有効カットオフ電圧と周波数(毎サンプル計算):
```
V  = clamp(clamp(cutoff,-5,6) + cv1 + l2*cv2 + l3*cv3, -10, 10)   // l2=clamp(cv2_level,-1,1), l3=clamp(cv3_level,-1,1)
fc = clamp(261.6256 * 2^V, 8, min(20000, 0.45*fs))                // Hz
```
- 上式の261.6256 HzはC4(COM-03)。`cv1`に`pitch`型(1 V/octのcv)の出力をつなぐと、`res=0.8`以上でfcに近い周波数の発振が音階を追従する(§10 TV-05)。

## 5. 内部状態と初期化・リセット
- 状態変数: `s[0..3]`(4個のTPT積分器の状態。float、初期値すべて 0.0)。
- 保存対象に含まないもの: 係数(`g`, `G`, `k`)は毎サンプル再計算するため状態ではない。
- `reset()`: `s[0..3] = 0`。パラメータは変えない。PRNGは使わない。
- RESET入力ポート: なし(該当なし: リセット入力を持たない)。
- `fs`変更時: COM-05に従い全状態を0へ再初期化する。

## 6. 振る舞い
1サンプルの処理(`x`=`in`, 未接続・非有限は0。他の入力も同様):
```
// 1) 入力を読む
x, cv1, cv2, cv3, rcv = 各入力(未接続=0、NaN/inf=0)
// 2) 係数(サンプル毎。上記 V, fc を使う)
g  = tan(pi * fc / fs)                    // プリワープ。fc <= 0.45*fs なので g <= 6.31
G  = g / (1 + g)
r  = clamp(res + 0.1*rcv, 0, 1);   k = 5.0 * r
// 3) 状態更新(零遅延フィードバックの解)
sg[i] = s[i] / (1 + g)                    // i = 0..3
S     = G^3*sg[0] + G^2*sg[1] + G*sg[2] + sg[3]
xn    = x / 5.0
y4e   = (G^4*xn + S) / (1 + k*G^4)        // 線形の場合の段4出力(フィードバックが同サンプルで閉じた解)
fb    = 4.0 * tanh(k * y4e / 4.0)         // 小信号では k*y4e。大振幅で飽和
u     = xn - fb
inp = u
for i in 0..3:                            // 段1→段4の順
    yi   = G*inp + sg[i]
    s[i] = 2*yi - s[i]
    inp  = yi
// 4) 出力
y = 5.0 * inp                             // inp は段4の出力
if 全 s[i] が有限でない or y が非有限: s[] = 0, y = 0   // COM-12
out = clamp(y, -12, +12)
```
- 各段は `H(z) = [g/(1+g)] · (1+z^-1) / (1 − [(1−g)/(1+g)] z^-1)` の1極ローパス(DC利得1、fcで -3 dB)。4段縦続で、DC利得 `1/(1+k)`(`k·y4e/4`が小さいとき)、`res=0` のときfcで利得 0.25(-12 dB)、fcの2倍・4倍での利得は§10 TV-04に値がある。
- `k = 4`(`res=0.8`)以上で、線形の極が単位円を越えて自己発振が起こる。小さな入力から振幅が育ち、フィードバック飽和(`4·tanh(k·y4/4)`)で制限される。`res=1`(`k=5`)、`cutoff=3 V`では出力振幅が約4.17 V、周波数が約fc(±1%)で持続する(§10 TV-05)。[A]
- サンプルレート依存: `g = tan(π·fc/fs)`、上限 `0.45·fs`。`fs`を変えるとfcの上限と係数が変わる(下限は8 Hz固定)。サポート範囲は `fs >= 8000 Hz`。[A]

## 7. 共通規約との関係
- COM-01: `in`/`out`は`audio`、`cv1`は`pitch`、`cv2`/`cv3`/`res_cv`は`cv`。型違い接続は許可。
- COM-02/12: 出力は±12 Vでクリップ。非有限入力は0 V。非有限状態は0へ戻す。
- COM-05/06: 1サンプル1ステップ。パラメータ変更は次ステップから。モジュール内部のフィードバックは同サンプルで解く(ケーブル遅延は付けない)。
- COM-09: すべての入力は未接続で0 V。normallingはなし。
- COM-10/14: 初期状態とreset、保存復元は§5・§9。
- COM-07: 複数のイベント入力を持たないため同時発生順序は該当しない。COM-11(乱数)は使わない。
- COM-08(ポリフォニー): モノを正本とし、ポリ入力時はチャンネルごとに独立の状態`s[0..3]`を持ち同じ式を適用する。チャンネル間の相互作用はない。

## 8. 異常入力・境界・数値安定性
- 入力のNaN/∞は0 Vとして扱う。パラメータがNaNのときは既定値(§4)。
- 範囲外パラメータはクランプ(`cutoff`は-5〜6、`res`は0〜1、`cv2_level`/`cv3_level`は-1〜1)。有効電圧`V`は±10 Vでクランプし、`2^V`のオーバーフローを避ける。
- 巨大入力(例 1e6 V)でも本線は線形なので有限のまま。出力は±12 Vでクリップされる(TV-07)。状態が非有限になった場合のみ状態を0に戻す。
- ゼロ割り: `1+g`は常に1より大きい。`1+k·G^4`は1以上。0割りは起こらない。
- DC: DC入力は通過する(DC利得 `1/(1+k)`)。ADCカップリングは行わない(DC結合)。[A]
- 非正規化数: 実装が0へ丸めてよい(許容誤差に影響しない。COM-12)。
- 高いカットオフ(fc近傍がナイキストに近い)ではTPTの周波数ワープにより、ステップ応答にオーバーシュートが出る(例 fc=20 kHz, fs=48 kHzで5 V入力に対し出力が5.39 V)。機能仕様どおりの挙動である。

## 9. 保存・復元・版互換
- 保存対象: ①パラメータ4個(`cutoff`, `res`, `cv2_level`, `cv3_level`)、②内部状態 `s[0..3]`、③PRNG状態: なし(乱数を使わない)、④`spec_id=MOD-FLT-001`と版`0.1`。
- 復元同値性(COM-14): 保存直後から復元したモジュールは、同一の入力列に対し保存しない場合とビット同一の出力列を返す(§10 TV-10)。係数は毎サンプル再計算するため保存不要。
- 版移行: 初版のため該当なし。

音質要件(機能再現とは別。数値目標は固定しない):
- エイリアシング: フィードバック飽和 `tanh` と高カットオフ時の自己発振は、オーバーサンプリングなしでは高調波が折り返す。測定方法: res=1.0・fc=8 kHz付近の自己発振出力を n=8192点のハン窓FFTでスペクトルを取り、基本波に対する折り返し成分のレベルを記録する(目標値は#3の音質評価で決める)。
- 自己発振の音程精度: cutoff を-3〜+6 Vで1 Vずつ変え、ゼロ交差法で周波数を測り、`261.6256·2^V` との比(cent)を記録する。TV-05は2093 Hzで-0.03%(約-0.5 cent)。res=1.0で cutoff=-3〜+6 Vを1 Vずつ変えた測定(ゼロ交差法、8000サンプル窓)では、-0.83〜+0.23 centの範囲に収まった(振幅は6 Vで3.39 V、他は4.0〜4.17 V)。これは測定結果であり保証値ではない。resが0.9以下ではfcからずれる(res=0.9, -3 Vで+3%)。
- 周波数応答: res=0で1 kHz〜20 kHzのスイープを入れ、fc近傍の -3 dB(0.25に対応する-12 dB点)とfcより高域の傾きを記録する。TPTはプリワープでfcの位置を合わせるが、ナイキスト近傍では解析ローパスと傾きが異なる。
