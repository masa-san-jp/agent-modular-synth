# MOD-SEQ-001 ステップシーケンサ

## 1. 目的と範囲
- 目的: CLOCK入力の立ち上がりごとに現在位置(ステップ)を1つ進め、そのステップに設定された電圧(CV)とゲート有無を出力する。RESET入力で位置を先頭へ戻す。入力(CLOCK/RESET)を読む → 位置・パルスカウンタ・グライド状態を更新 → CV/GATE/TRIG/EOC を書く、を1サンプルで行う。
- 含む: 最大16ステップの前進再生、ステップ毎のCV(単一行)とゲート有無、グライド(CVの1次平滑)、RESET、実行/停止、1周完了パルス(EOC)。
- 含まない: 保存メモリ構造(複数パターンの記憶。catalogの方針)、内部クロック(MOD-CLK-001を接続する)、スイング/ラチェット/ステップ毎ゲート長/方向切替(§11)、ポリフォニー固有処理、A-155の第2アナログ行と3本のトリガトラックの個別出力(§2 S-10)。

## 3. ポート
| 名前 | 方向 | 型 | ch | 単位 | 範囲 | 更新周期 | 未接続時 |
|---|---|---|---|---|---|---|---|
| CLOCK | in | clock | 1 | V | 任意の有限値(COM-04で二値化: ON 2.0 V以上 / OFF 0.1 V以下) | サンプル毎 | 0 V(立ち上がりなし。位置は進まない) |
| RESET | in | trigger | 1 | V | 任意の有限値(COM-04で二値化) | サンプル毎 | 0 V(リセットなし) |
| CV | out | cv | 1 | V | −10〜+10(グライド中も範囲内。COM-02により±12 Vでクランプ) | サンプル毎 | 出力は未接続でも通常どおり計算 |
| GATE | out | gate | 1 | V | 0 または 10 | サンプル毎 | 出力は未接続でも通常どおり計算 |
| TRIG | out | trigger | 1 | V | 0 または 10(幅 `Nt=max(1,round(0.001·fs))` サンプル) | サンプル毎 | 出力は未接続でも通常どおり計算 |
| EOC | out | trigger | 1 | V | 0 または 10(幅 `Nt` サンプル) | サンプル毎 | 出力は未接続でも通常どおり計算 |

- 型違い接続は許可(COM-01)。ポートはすべてモノ(1ch)。ポリ入力が来た場合は1ch目のみ使う。[A] (COM-08の初期方針)
- 現在位置(`pos`、0始まり)は状態読出しとして外部インターフェースから取得できる(ポートではない)。

## 4. パラメータ
| 名前 | 単位 | 範囲 | 既定値 | 変調 | 更新タイミング | 補間 |
|---|---|---|---|---|---|---|
| length | ステップ(整数) | 1〜16。最近接整数へ四捨五入(0.5は切り上げ)してからクランプ(COM-13)。NaN/∞は既定8 | 8 | なし(CV入力を持たない) | 次のステップ(§6 のpos処理は毎サンプル `length` を読む) | なし(階段状) |
| cv[i] (i=1..16) | V | −10〜+10。有限の範囲外はクランプ。NaN/∞は既定0 | 0 | なし | 次のステップ | CV出力に限りglideで平滑(§6) |
| gate[i] (i=1..16) | 真偽(0/1) | 0 または 1(有限の0以外は1。NaN/∞は既定1) | 1 | なし | 次のステップ | なし |
| glide | 秒(時定数τ。COM-17の「時定数」) | 0〜10。有限の範囲外はクランプ。0は平滑なし。NaN/∞は既定0 | 0 | なし | 次のステップ | 係数を毎サンプル再計算(`fs`依存式は§6) |
| run | 真偽(0/1) | 0 または 1(有限の0以外は1。NaN/∞は既定1) | 1 | なし | 次のステップ | なし |

- ステップ番号は仕様上1始まり(`cv[1]` が最初のステップ)、内部の `pos` は0始まり(`pos=0` が `cv[1]`)。
- `cv[i]`、`gate[i]` は `i > length` でも保持される(再生には使われないだけ)。
- パラメータのNaN/∞は**既定値**として扱い(length=8, cv[i]=0, gate[i]=1, glide=0, run=1。COM-12)、有限の範囲外値はクランプ、整数型の `length` は四捨五入後にクランプする(COM-13)。両者を区別する(例: `length=+∞` は16でなく8、`length=99` は16)。
- CV入力ポートを持たないため、CV感度(COM-18)はない。
- 乱数は使わないため `seed` パラメータはない。

## 5. 内部状態と初期化・リセット
状態変数(型・初期値):
| 名前 | 型 | 初期値 | 意味 |
|---|---|---|---|
| pos | int, 0〜15 | 0 | 選択ステップ(0始まり) |
| clk_state | 0/1 | 0 | CLOCKのシュミット状態(COM-04) |
| rst_state | 0/1 | 0 | RESETのシュミット状態 |
| hold | int ≥ 0 | 0 | RESET後のCLOCK無視の残りサンプル数 |
| trig_cnt | int ≥ 0 | 0 | TRIGパルスの残りサンプル数 |
| eoc_cnt | int ≥ 0 | 0 | EOCパルスの残りサンプル数 |
| cv_y | float | 0.0 | グライド後のCV(出力値) |

- `reset()`(COM-10): 上表を初期値へ戻す。パラメータは変えない。`cv_y=0` から始まるため、`glide>0` なら最初のサンプルで出力が0 Vからステップ1のCVへ接近する。
- リセットの種類(COM-10): `reset()` は**全体リセット**(`cv_y` も0へ)、RESET入力は**音楽的リセット**(`pos=0`。TRIG/EOCは出さない。`cv_y`は保持。GATEとCVはステップ1の値を即座に出す)。
- RESET入力(音楽的リセット): `pos=0`、`hold=Nh`、`trig_cnt=0`、`eoc_cnt=0` にする。`cv_y`は戻さない(グライド状態を保つ)。`clk_state`/`rst_state`は変えない。

## 6. 振る舞い
サンプルレート依存の定数(`fs`はCOM-05。既定48000 Hz):
```
Nt = max(1, round(0.001 * fs))      // TRIG/EOCの幅 (COM-04)。fs=48000で48, fs=44100で44
Nh = ceil(0.001 * fs)               // RESET後のCLOCK無視区間 (COM-07)。fs=48000で48, fs=44100で45
a  = (glide <= 0) ? 1 : 1 - exp(-1 / (glide * fs))     // グライドの1サンプル係数
```
1サンプルの処理(入力を読む → 状態更新 → 出力。順序はCOM-07のRESET → CLOCK → 連続値):
```
// 0. 入力の読出し。NaN/±∞は0 Vとして扱う (COM-12)。未接続は0 V (COM-09)
c = finite(CLOCK) ? CLOCK : 0;   r = finite(RESET) ? RESET : 0
// 1. シュミット (COM-04)。無視区間中も状態は更新する
rst_edge = (rst_state==0 && r >= 2.0);  rst_state = update(rst_state, r)
clk_edge = (clk_state==0 && c >= 2.0);  clk_state = update(clk_state, c)
L = clamp(round(finite(length) ? length : 8), 1, 16)      // 四捨五入(0.5切り上げ)→クランプ。NaN/∞は既定8(COM-12/13)
if pos >= L: pos = 0                         // length縮小時。EOCは出さない
// 2. RESET (最優先)
if rst_edge: pos = 0; hold = Nh; trig_cnt = 0; eoc_cnt = 0
else if hold > 0: hold = hold - 1
// 3. CLOCK。RESETと同一サンプルならhold>0なので無視される
if run && clk_edge && hold == 0:
    p = pos + 1;  wrapped = (p >= L);  if wrapped: p = 0
    pos = p
    if gate[pos+1] != 0: trig_cnt = Nt
    if wrapped:          eoc_cnt  = Nt
// 4. 連続値 (グライド)
target = clamp(finite(cv[pos+1]) ? cv[pos+1] : 0, -10, 10)   // パラメータcv[i]のNaN/∞は既定0
cv_y   = cv_y + a * (target - cv_y)
// 5. 出力
CV   = clamp(cv_y, -12, 12)
GATE = (run && gate[pos+1] != 0) ? 10 : 0
TRIG = (trig_cnt > 0) ? 10 : 0;   if trig_cnt > 0: trig_cnt -= 1   // 書いた後に減算
EOC  = (eoc_cnt  > 0) ? 10 : 0;   if eoc_cnt  > 0: eoc_cnt  -= 1
```
- `gate[i]` のNaN/∞は1、`glide` のNaN/∞は0、`run` のNaN/∞は1として扱う(上の擬似コードの `gate[…] != 0`、`a`、`run` はこの整形後の値)。
- `hold` は「RESETのサンプル(n)から数えて `Nh` サンプルの間」CLOCKを無視する: RESETをn、無視されるCLOCKの立ち上がりは `n … n+Nh−1`、受理されるのは `n+Nh` 以降。
- グライドの閉形式: 位置の切替をサンプル `m` で行い `glide>0` のとき、切替前の値 `y0`、新ターゲット `T` なら `cv_y[m+k] = T − (T − y0)·exp(−(k+1)/(glide·fs))`(k=0,1,…)。
- GATEは選択ステップの間ずっとhigh(`gate=1`のステップが連続すればhighのまま。再トリガはTRIGで表す)。
- 同じパラメータ・同じ入力列から出力は決定的に定まる。乱数は使わない。

## 7. 共通規約との関係
- COM-04: CLOCK/RESETの二値化、GATE=10 V、TRIG/EOC幅1 ms。
- COM-05/06: 1サンプル=1ステップ。モジュール単体の検証は `x[n]→y[n]`。ケーブル遅延は接続時のみ。
- COM-07: 処理順は RESET → CLOCK → 連続値。RESET後 `Nh=ceil(0.001·fs)` サンプルのCLOCK無視は**採用する**(F-005-012)。
- COM-08: モノが正本。ポリ入力は1ch目のみ。[A]
- COM-09: 未接続のCLOCK/RESETは0 V(正規化なし)。
- COM-10: `reset()` とRESET入力の違いは§5。
- COM-12: 入力のNaN/∞は0 V扱い。出力は常に有限(CVは±12 Vでクランプ)。
- COM-12: 入力のNaN/∞は0 V、パラメータのNaN/∞は既定値。
- COM-13: パラメータ範囲外はクランプ、整数型の `length` は四捨五入→クランプ。CV入力を持たないため変調式はない。
- COM-14: §9。
- 固有: 乱数なし(COM-11は使わない)。トリガ幅 `Nt`(round)と無視区間 `Nh`(ceil)は共通規約どおりで、fs=44100では44と45で異なる。

## 8. 異常入力・境界・数値安定性
- CLOCK/RESETがNaN/±∞: 0 Vとして扱う。high状態からNaNが来るとOFF閾値以下とみなされて状態がlowに戻り、次の有限highで新たな立ち上がりが生じる。
- パラメータのNaN/∞は既定値(length=8, cv[i]=0, gate[i]=1, glide=0, run=1。TV-14)。
- `length` は四捨五入(0.5は切り上げ)後にクランプ: 0以下・0.4は1、3.5は4、2.4は2、17以上は16(TV-03 (c)(d))。`length=1` では毎CLOCKで常にwrapし、EOCとTRIG(gate[1]=1のとき)が毎回出る。
- `length` を再生中に縮小し `pos >= length` になった場合、次のサンプルで `pos=0` に戻す(EOCなし)。
- `cv[i]` 範囲外は±10 Vにクランプ。`glide` 負値は0、10超は10。
- CLOCKがhighのまま保たれる場合、新しい立ち上がりまで進まない。パルス幅は無視される。
- `run=0` の間、CLOCKは無視されるが、エッジ検出状態は更新される(再開直後にhigh継続中のCLOCKで進むことはない)。
- 数値: `a` は `glide·fs` が0に近い小さな正値でも `exp(−大)` が0へ収束するだけで安全。`glide>0` で `glide·fs < 1` の場合は `a≒1−exp(−1/(glide·fs)) ≒ 1`。
- 過大出力: CVは±12 Vを超えない(パラメータが±10にクランプされるため通常は超えない)。

## 9. 保存・復元・版互換
- 保存対象: ①パラメータ(`length`、`cv[1..16]`、`gate[1..16]`、`glide`、`run`)、②内部状態(`pos`、`clk_state`、`rst_state`、`hold`、`trig_cnt`、`eoc_cnt`、`cv_y`)、③PRNG状態: なし(乱数を使わない)、④`spec_id=MOD-SEQ-001`、仕様版 `0.1`。
- 復元後は同じ入力列に対しビット同一の出力列を返す(検証例 TV-MOD-SEQ-001-13)。
- 版移行: 初版のため該当なし。将来、方向切替などを追加する場合は欠けたパラメータに既定値(順方向)を補う。

### 音質・時間精度に関する要件(機能再現とは別項)
- 本モジュールは波形を生成しないため、エイリアシング等の音質要件はない。CVのグライドは1次の指数接近であり、原機(M006)の実際のglide曲線を再現するものではない。
- 時間精度: イベントの時刻はサンプル単位(COM-07)。測定方法: CLOCK立ち上がりのサンプル番号 `n_c` と、CV/GATE/TRIGが変化するサンプル番号 `n_o` を比較し、モジュール単体では `n_o = n_c`(同一サンプル。ケーブル遅延1サンプルは接続時にのみ加わる)であること。
