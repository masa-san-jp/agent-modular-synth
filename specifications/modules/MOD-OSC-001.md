# MOD-OSC-001 VCO(電圧制御オシレータ)

## 1. 目的と範囲
- 目的: 1 V/oct のピッチ入力から周波数を決め、位相アキュムレータを1サンプルずつ進めて、ノコギリ・矩形・三角・正弦の4波形を同時に出力する。ノコギリ・矩形・三角は帯域制限して出す(折り返し雑音を減らす。§6)。`sync` 入力の立ち上がりで位相を0へ戻す(ハードシンク)。
- 含む: 4波形同時出力、1 V/oct、レンジ・チューン、指数FM(`fm` 入力)、パルス幅(手動とCV)、ハードシンク、帯域制限(段差に PolyBLEP、角に PolyBLAMP。DEC-028)。
- 含まない: アナログ核の非線形・温度ドリフト・チューニング誤差・波形の非理想性(catalog.md の方針)、リニアFM、サブオシレータ、ハードシンクの段差の帯域制限(§6)、ポリフォニー固有の相互作用(COM-08)。

方式選択: 位相アキュムレータ(位相 `p∈[0,1)`)から4波形を式で直接生成し、段差と角の前後1サンプルずつに多項式の補正を足す(PolyBLEP / PolyBLAMP)。補正は位相と `dphi` だけで決まるので、状態変数は増えない(§5)。原機の「ノコギリコアから他波形を派生」(REF-001-005)とは内部構成が異なるが、公称出力の機能は一致させる。周波数範囲は原機の15 Hz〜8 kHz に限定せず、`dphi ≤ 0.5` までを許す(S-01は目安)。

## 4. パラメータ
| 名前 | 単位 | 範囲 | 既定値 | 変調 | 更新タイミング | 補間 |
|---|---|---|---|---|---|---|
| range | oct(整数) | -2, -1, 0, +1, +2(最近接整数へ四捨五入(0.5は切り上げ)した後に範囲へクランプ。COM-13) | 0 | 不可 | 次のステップ | なし(階段状) |
| tune | oct(=V) | -1.0 〜 +1.0 | 0.0 | 不可 | 次のステップ | なし(階段状。位相は連続) |
| fm_amt | oct/V | -1.0 〜 +1.0 | 0.0 | `fm` 入力の感度 k(指数型、COM-18。単位 oct/V) | 次のステップ | なし |
| pw | 比(デューティ) | 0.02 〜 0.98 | 0.5 | 可(加算型、COM-18): `pwm` 入力で `pw_eff = clamp(pw + pwm_amt·pwm/10)` | 次のステップ | なし |
| pwm_amt | 比/10 V(`pwm` が10 Vのとき `pw` に加わる量) | -1.0 〜 +1.0 | 0.0 | `pwm` 入力の感度 k(加算型の感度。k = pwm_amt/10 [比/V]) | 次のステップ | なし |

- 範囲外の値は範囲の端へクランプする(COM-13)。NaN/∞ のパラメータは既定値として扱う。[A]
- CV感度(COM-18): `fm` は**指数型**(周波数が `2^(fm_amt·fm)` 倍、感度 `fm_amt` は oct/V)、`pwm` は**加算型**(感度 `pwm_amt/10` 比/V)。`pitch` は 1 V/oct の指数型(感度は固定の1 oct/V)。`tune`・`range` は V(=oct)として `pitch` に加算される。
- `range`・`tune`・`fm_amt`・`pw`・`pwm_amt` は§6の式を適用する前に、このとおり正規化する(range は四捨五入→クランプ、他はクランプ、NaN/∞ は既定値)。
- 出力レベルは固定の公称値(§3)で、`gain`/`level` に当たるパラメータはない。

## 5. 内部状態と初期化・リセット
- 状態変数:
  - `phase`: 64bit浮動小数点(double)、範囲 [0,1)、初期値 0.0。位相は float32 でなく double で保持する(長時間の位相誤差を抑えるため。[A])。
  - `sync_state`: 0/1(COM-04のシュミット状態)、初期値 0。
- `reset()`: `phase = 0.0`、`sync_state = 0`。パラメータは変えない(COM-10)。
- **ポリフォニー時**(COM-08): `phase` と `sync_state` は**エンジン(チャンネル)ごとに1組**持つ(`N` 組)。`reset()` は全エンジンに同時に適用する。`N` が変わったとき(`pitch` の接続やチャンネル数の変更)は、増えたエンジンを初期状態(`phase = 0.0`、`sync_state = 0`)から開始し、減ったエンジンの状態は破棄する。残るエンジンの状態は変えない。パラメータは全エンジンで共有する。[A]
- RESET入力ポート: 持たない(`sync` が位相リセットの役を持つ。`sync` は `reset()` と別物で、`phase` のみを0にし `sync_state` はシュミット判定で更新する)。

## 6. 振る舞い
1サンプルの処理(COM-05/06/07準拠。パラメータはステップ開始時の値):
```
// 入力を読む(接続なしは §3 の未接続時の値、NaN/∞ は 0 V、COM-12)
x_pitch, x_fm, x_pwm, x_sync = 各入力(finite でなければ 0)

// 1. sync(イベント)を最初に処理(COM-07: RESET/トリガ類 → 連続値)
rising = schmitt(sync_state, x_sync)     // ON閾値2.0 V / OFF閾値0.1 V(COM-04)
if rising: phase = 0.0                   // このサンプルの出力は位相0から計算される

// 2. 周波数
V    = clamp(x_pitch + range + tune + fm_amt * x_fm, -10, +10)   // range, tune, fm_amt は§4で正規化済み(range は四捨五入→クランプ)
f    = 261.6256 * 2^V                    // Hz(COM-03)
dphi = min(f / fs, 0.5)                  // 位相増分。サンプルレート依存はここだけ

// 3. パルス幅
pw_eff = clamp(clamp(pw,0.02,0.98) + pwm_amt * x_pwm / 10, 0.02, 0.98)

// 4. 波形(現在の phase から計算してから位相を進める)。ナイーブな形に、段差と角の補正を足す(帯域制限)
dist(d)  = u / dphi   // u = phase - d を [-0.5, 0.5) に折り返した値(u ≥ 0.5 なら u-1、u < -0.5 なら u+1)。位置 d からの距離(サンプル)
blep(x)  = 0 ≤ x < 1 : -(1-x)²/2;   -1 ≤ x < 0 : (1+x)²/2;   それ以外: 0   // 高さ1の段差の補正(PolyBLEP)
blamp(x) = 0 ≤ x < 1 : (1-x)³/6;    -1 ≤ x < 0 : (1+x)³/6;   それ以外: 0   // 傾きが1サンプルあたり1変わる角の補正(PolyBLAMP)
b0    = blep(dist(0))                    // 位相0の段差(saw は -8 V、pulse は +8 V)
bpw   = blep(dist(pw_eff))               // 位相 pw_eff の段差(pulse は -8 V)
k     = 40 * dphi                        // tri の角での傾きの変化(1サンプルあたり。p=0.25 で -k、p=0.75 で +k)
saw   = 4 * (2*phase - 1) - 8*b0
pulse = ((phase < pw_eff) ? +4 : -4) + 8*b0 - 8*bpw
x     = phase<0.25 ? phase : (phase<0.75 ? 0.5-phase : phase-1)
tri   = 20 * x - k*blamp(dist(0.25)) + k*blamp(dist(0.75))   // 0→+5(p=0.25)→-5(p=0.75)→0。角は丸まる
sine  = 5 * sin(2π * phase)

// 5. 状態更新
phase = phase + dphi;  if phase >= 1.0: phase -= 1.0      // dphi ≤ 0.5 なので1回の減算で足りる

// 6. 出力(各出力が NaN/∞ なら 0、COM-12)
```
- ステップ `n` の出力は「`n` 回目の位相更新前」の位相から計算する。同期なしで入力が一定なら `phase[n] = n·dphi mod 1`。
- `sync` が立ち上がったサンプルでは位相0の出力が書かれ、次のステップは `dphi` から進む。`sync` が high のまま続いても、立ち上がりのサンプルでのみ位相が戻る。
- ピッチ変化は階段状に周波数へ反映される(補間なし)。位相は常に連続で、ピッチ変更自体が位相を飛ばすことはない。
- 周波数クランプ: `V` を ±10 に制限して `f` は約0.2555 Hz 〜 267.9 kHz。上側は `dphi ≤ 0.5`(f ≤ fs/2)で上限が決まる。 [A]
- 帯域制限の補正(PolyBLEP / PolyBLAMP)が0でないのは、段差・角の位置の直前1サンプルと直後1サンプルだけ。それ以外のサンプルはナイーブな式と同じ値になる。段差の位置ちょうど(`dist = 0`)のサンプルは段差の中点になる。補正は今の `dphi` と `pw_eff` で計算し、次の段差の位置を「`dphi` が変わらない」として見込む(周波数やパルス幅が変わる途中の補正は近似)。[A]
- 位相0は段差の直後として扱う。そのため、開始時・`reset()` の後・`sync` の立ち上がりのサンプルでは、ノコギリと矩形は 0 V(位相0の段差の中点)を出す。`sync` で実際に起きる段差の高さは、そのときの位相で決まり、位相0の段差(8 V)と一致しない。`sync` はサンプル単位で起きるので段差の正確な位置が分からず、この段差は帯域制限しない(§11)。[A]

**音質要件(機能再現と分離)**
- ノコギリ・矩形・三角は帯域制限する(2サンプルの PolyBLEP / PolyBLAMP。DEC-028)が、折り返し雑音は残る(高い音ほど多い)。測定値は `docs/perf/20261127-osc-aliasing-band-limited.md`(VER-NF-007a)。
- **暫定の目標(DEC-030)**: 下の測定方法(`fs`=48000、全帯域)で、折り返し成分の基本波比が次の値**以下**であること。仕様版 0.3 の測定値を 0 dB 側へ 1 dB 未満丸めた値で、今の音質より悪くしないための線である。聞き比べで決めた値ではないので、試聴(VER-NF-007j)の後に見直す。正弦は対象にしない(帯域制限の対象外で、折り返しは計算の丸めの大きさ)。4000 Hz は測定方法の死角のため(下記)、4186.0096 Hz(`pitch`=+4 V)で代える。
  | 周波数 | ノコギリ | 矩形 | 三角 |
  |---|---|---|---|
  | 440 Hz | −42 dB | −42 dB | −77 dB |
  | 4186.0096 Hz | −23 dB | −28 dB | −45 dB |
  | 10000 Hz | −20 dB | −20 dB | −30 dB |
- 測定方法(参考。数値目標は根拠がないため固定しない): `fs=48000`、`pitch` 一定・他は既定値で各波形を 2^16 サンプル取得し、Hann窓のFFTで振幅スペクトルを求める。基本波とその整数倍高調波(0倍=直流を含む)の位置から ±3 ビンを除き、残りのビンの山(両隣より大きいビン)のうち最大のものを「折り返し成分」とし、基本波の山との比(dB)を報告する。山だけを数えるのは、強い高調波の窓の裾(山を持たない)を数えないため。周波数を変えて(例: 440 Hz, 4 kHz, 10 kHz)比較する。`fs` の整数分の1の周波数(例: 4 kHz = 48000/12)では周期が整数サンプルになり、折り返した成分がすべて高調波の位置に重なるので、この方法では見えない。そのような周波数では、周期が整数サンプルにならない近くの周波数(例: `pitch`=+4 V の 4186.0096 Hz)も測る。同じ周波数のまま `fs` を変えて(例: `fs`=44100)測ってもよい。測定の道具は `tools/measure-osc-aliasing.mjs`(`--fs` で `fs` を変える)。[A]

## 7. 共通規約との関係
- COM-01/02: 出力は ±5 V 以内で ±12 V を超えない(COM-02(3))。入力は範囲外でも黙って切り捨てず、`V` のクランプは周波数の安全範囲の制限であり波形電圧の切り捨てではない。
- COM-03: `f = f0·2^V` の `f0 = 261.6256 Hz`。本仕様の `V = pitch + range + tune + fm_amt·fm`(COM-18の指数型。`fm` の感度は `fm_amt`)で、`f = 261.6256·2^V`。`pitch = 0 V` が C4 になるのは**既定パラメータのとき(`range=0`, `tune=0`, かつ `fm_amt·fm = 0`)だけ**で、`range` や `tune` を変えればその分だけ `pitch = 0 V` の周波数も動く。COM-04: `sync` はシュミット判定。COM-05/06: 1サンプル処理、出力は次ステップに接続先から見える。
- COM-07: 同一ステップの順序は sync → 周波数計算 → 波形生成 → 位相更新。「RESET後1 msのCLOCK無視」は CLOCK入力を持たないため該当しない。
- COM-09: 未接続時は §3 の値。COM-10/12/13/14: §5・§8・§4・§9 に記載。
- COM-08(ポリフォニー): モノを正本とし、エンジン `c`(0始まり)ごとに§6の式を独立に適用する。チャンネル間の相互作用はない。[A]
  - **主入力は `pitch` のみ**。`N` = `pitch` のチャンネル数(未接続なら `N = 1`)。出力 `saw`/`pulse`/`tri`/`sine` は `N` チャンネル。理由: (i) ポリフォニーの声部はピッチCV(MOD-IO-002 等の `pitch` 出力)のチャンネルで決まり、VCOは1声につき1つの周波数を作るモジュールであること、(ii) `fm`・`pwm`・`sync` は周波数・パルス幅・位相を**変調する**入力で、単独では声部の数を決める意味を持たないこと(全声に同じLFOを掛ける使い方が普通で、これは1チャンネルのコピーで表せる)、(iii) 主入力を1つにすると `N` が接続の組み合わせに依存せず分かりやすいこと。
  - **副入力は `fm`・`pwm`・`sync`**。COM-08の副入力の規則どおり: 1チャンネルなら全エンジンへコピー、`N` チャンネル以上ならエンジン `c` はチャンネル `c` を使い(`N` 以上の番号のチャンネルは読まない)、2以上 `N` 未満なら不足するエンジンは 0 V(`fm`=0 V は変調なし、`sync`=0 V は同期なし)。未接続は全エンジン 0 V(§3)。
  - 帰結: `pitch` が未接続なら、`fm` 等が複数チャンネルでも `N = 1` で、各副入力の1チャンネル目だけを使う(TV-MOD-OSC-001-13)。`sync` を1チャンネルで与えると全エンジンが同じサンプルで位相0に戻る(TV-MOD-OSC-001-12)。
  - 乱数は使わないため、エンジンごとの seed の規則(COM-08/COM-11)は該当しない。
- 固有: `sync` と `reset()` の区別(§5)。

## 8. 異常入力・境界・数値安定性
- 入力の NaN/±∞ は 0 V として扱う(COM-12)。パラメータの NaN/∞ は既定値。
- **置換カウンタ**(COM-12 の `nonfinite_count`): `pitch`・`fm`・`pwm`・`sync` の各入力で、読んだ値が NaN/±∞ で 0 V に置換したとき、1ポート・1チャンネル・1サンプルにつき1増やす(`fm_amt = 0` などで結果に影響しない場合も、読んで置換した時点で数える)。数えるのは**ポートのチャンネル値**で、1チャンネルの副入力を `N` エンジンへコピーする場合も1サンプルにつき1(`N` ではない)。読まないチャンネル(副入力の `N` 以上の番号)と未接続の入力は数えない。出力(`saw`/`pulse`/`tri`/`sine`)は有限の `phase` とクランプ済みの値から計算するため NaN/∞ にならず、出力側の置換は起こらない(増分は常に0)。パラメータの NaN/∞ は数えない。`reset()` で 0 に戻る(TV-MOD-OSC-001-07、-14)。
- `pitch` が大きい: `V` を ±10 にクランプ。`dphi` は 0.5 を超えない(f=fs/2 のとき位相は 0, 0.5 を交互にとり、帯域制限により saw・pulse・tri・sine はすべて 0 になる)。
- `pitch` が小さい: V=-10 で f≈0.2555 Hz。位相は進み続け、停止しない(ゼロ周波数はない)。
- `pw` は 0.02〜0.98 にクランプし、矩形が常に一定値(DC)になることを避ける。`pwm` が大きくても `pw_eff` は同範囲に収まる。`dphi` が `pw_eff` や `1-pw_eff` より大きいときは、2つの段差の補正が同じサンプルに重なり、そのまま足す(TV-MOD-OSC-001-06)。
- 補正を足しても出力は §3 の範囲に収まる: |saw| ≤ 4、|pulse| ≤ 4、|tri| ≤ 5(`dphi` を 1/400〜0.5、`pw_eff` を 0.02〜0.98、位相を 1/2000 刻みで総当たりした最大は 3.98、4.0、4.983)。
- `phase` は double で `[0,1)` を保つ。`phase >= 1` のとき減算するため `phase=1.0` は出力されない。
- 出力は `±0` と `-0` を同一視してよい。DCは出ない(saw/tri/sine は一周期平均0、pulse は `pw_eff≠0.5` で平均が0でない)。
- 演算精度: 位相と波形は倍精度で計算し、出力ポートへ書く時点で float32 に丸める。(2026-11-20、実装で補った解釈を明文化)

## 9. 保存・復元・版互換
- 保存対象(COM-14): パラメータ5個、`phase`(double)、`sync_state`(ポリフォニー時はエンジンごとに `N` 組と `N`)、`spec_id=MOD-OSC-001`、仕様版 0.3。PRNGは使わないため保存しない。`nonfinite_count` は診断値で保存対象外(COM-12)。
- 復元後は、同じ入力列に対し保存しなかった場合とビット同一の出力列を返す(TV-MOD-OSC-001-09)。`phase` を float32 へ丸めて保存してはならない。
- 版移行(0.1 → 0.2): **移行不要**。0.2 での変更点は、(1) ポリフォニーの規則の明記(主入力 `pitch`、副入力 `fm`/`pwm`/`sync`、エンジンごとの状態。§3・§5・§7)、(2) 置換カウンタ `nonfinite_count` の適用(§8)、(3) ポリ時と置換カウンタの検証例の追加(§10)。パラメータの追加・意味の変更はなく、モノ(1チャンネル)の振る舞いと既存の検証例の期待値は 0.1 と同じ。0.1 のパッチ(パラメータ5個)はそのまま読める。0.1 のスナップショット(`phase`、`sync_state` が1組)はエンジン0の状態として読む。
- 版移行(0.2 → 0.3): **移行不要**。0.3 での変更点は、ノコギリ・矩形・三角の帯域制限(§6、DEC-028)。パラメータ・ポート・状態変数の組と意味は変わらないので、0.2 のパッチはそのまま読める。ただし同じパッチ・同じ楽譜でも出力の音は変わる(段差と角の前後のサンプル)。検証例 TV-MOD-OSC-001-01〜06、09、11〜14 の期待値が変わり、TV-MOD-OSC-001-15 を足した。スナップショットは版が違うので移行しない(data-contract §6)。

## 11. 未確認・保留事項
- ポリフォニーの主入力を `pitch` だけとした(§7)。`pitch` 未接続のまま `fm` や `sync` だけを複数チャンネルにしても `N = 1` になる。`fm`・`sync` も主入力に含める案(`N` = 接続された入力の最大チャンネル数)は#3で見直し可。[A]
- 原機のレンジ5段ごとの周波数範囲、Tuneの幅(版差あり)、同期・リセット条件はDB未確認(M001 unknowns)。レンジとチューンの範囲、`sync` の仕様は[A]。#3で見直し可。
- 三角・正弦の「切れ込み」など原機の非理想性とアナログドリフトは再現しない。
- 帯域制限は2サンプルの PolyBLEP / PolyBLAMP とした(DEC-028)。折り返し雑音は残る(測定値: `docs/perf/20261127-osc-aliasing-band-limited.md`)。より減らす方式(4サンプル以上の多項式、minBLEP、オーバーサンプリング、帯域ごとの波形表)は、音質の目標(OPEN-006)が決まった時点で見直す。高域の減衰(2サンプルの補正は 15 kHz 付近の倍音を約 3 dB 下げる)とのかね合いがある。[A]
- `sync` の段差は帯域制限しない(位相0の段差として補正するだけ。§6)。サンプル単位より細かい同期の位置を扱う案は#3で見直し可。[A]
- リニアFM、PWM入力の感度(10 V=全幅)は#3で見直し可。
- 出力電圧の公称値(F-001-016は典型値)は保証値でなく、#3で正規化レベルを変える可能性がある。
