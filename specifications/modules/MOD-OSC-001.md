# MOD-OSC-001 VCO(電圧制御オシレータ)

## 1. 目的と範囲
- 目的: 1 V/oct のピッチ入力から周波数を決め、位相アキュムレータを1サンプルずつ進めて、ノコギリ・矩形・三角・正弦の4波形を同時に出力する。`sync` 入力の立ち上がりで位相を0へ戻す(ハードシンク)。
- 含む: 4波形同時出力、1 V/oct、レンジ・チューン、指数FM(`fm` 入力)、パルス幅(手動とCV)、ハードシンク。
- 含まない: アナログ核の非線形・温度ドリフト・チューニング誤差・波形の非理想性(catalog.md の方針)、リニアFM、サブオシレータ、バンドリミット(エイリアス抑制)、ポリフォニー固有の相互作用(COM-08)。

方式選択: 位相アキュムレータ(位相 `p∈[0,1)`)から4波形を式で直接生成する。原機の「ノコギリコアから他波形を派生」(REF-001-005)とは内部構成が異なるが、公称出力の機能は一致させる。周波数範囲は原機の15 Hz〜8 kHz に限定せず、`dphi ≤ 0.5` までを許す(S-01は目安)。

## 3. ポート
| 名前 | 方向 | 型 | ch | 単位 | 範囲 | 更新周期 | 未接続時 |
|---|---|---|---|---|---|---|---|

| fm | in | cv | 1 | V | 任意の有限値 | サンプル毎 | 0 V |
| pwm | in | cv | 1 | V | 任意の有限値(10 Vで幅±1.0相当、`pwm_amt` 倍) | サンプル毎 | 0 V |
| sync | in | trigger | 1 | V | 任意の有限値(COM-04のシュミット判定) | サンプル毎 | 0 V(同期なし) |
| saw | out | audio | 1 | V | -4 〜 +4 | サンプル毎 | (出力。未接続でも計算) |
| pulse | out | audio | 1 | V | -4 または +4 | サンプル毎 | (同上) |
| tri | out | audio | 1 | V | -5 〜 +5 | サンプル毎 | (同上) |
| sine | out | audio | 1 | V | -5 〜 +5 | サンプル毎 | (同上) |

ポリフォニー: COM-08の初期方針により、1チャンネルを正本とし、複数チャンネル時はチャンネルごとに独立の位相状態を持つ。

## 4. パラメータ
| 名前 | 単位 | 範囲 | 既定値 | 変調 | 更新タイミング | 補間 |
|---|---|---|---|---|---|---|
| range | oct(整数) | -2, -1, 0, +1, +2(範囲外は最寄りへクランプ後、整数へ丸め) | 0 | 不可 | 次のステップ | なし(階段状) |
| tune | oct(=V) | -1.0 〜 +1.0 | 0.0 | 不可 | 次のステップ | なし(階段状。位相は連続) |
| fm_amt | oct/V | -1.0 〜 +1.0 | 0.0 | `fm` 入力の感度 k | 次のステップ | なし |
| pw | 比(デューティ) | 0.02 〜 0.98 | 0.5 | `pwm` 入力で加算変調 | 次のステップ | なし |
| pwm_amt | 比/10 V | -1.0 〜 +1.0 | 0.0 | `pwm` 入力の感度 k | 次のステップ | なし |

- 範囲外の値は範囲の端へクランプする(COM-13)。NaN/∞ のパラメータは既定値として扱う。[A]
- 乱数は使わないため `seed` は持たない。

## 5. 内部状態と初期化・リセット
- 状態変数:
  - `phase`: 64bit浮動小数点(double)、範囲 [0,1)、初期値 0.0。位相は float32 でなく double で保持する(長時間の位相誤差を抑えるため。[A])。
  - `sync_state`: 0/1(COM-04のシュミット状態)、初期値 0。
- `reset()`: `phase = 0.0`、`sync_state = 0`。パラメータは変えない(COM-10)。
- RESET入力ポート: 持たない(`sync` が位相リセットの役を持つ。`sync` は `reset()` と別物で、`phase` のみを0にし `sync_state` はシュミット判定で更新する)。

## 6. 振る舞い
1サンプルの処理(COM-05/06/07準拠。パラメータはステップ開始時の値):
```
// 入力を読む(接続なしは §3 の未接続時の値、NaN/∞ は 0 V、COM-12)
x_pitch, x_fm, x_pwm, x_sync = 各入力(finite でなければ 0)

// 1. sync(イベント)を最初に処理(COM-07: RESET/トリガ類 → 連続値)
rising = schmitt(sync_state, x_sync)     // ON閾値2.0 V / OFF閾値0.1 V(COM-04)
if rising: phase = 0.0                   // このサンプルの出力は位相0から計算される

// 2. 周波数
V    = clamp(x_pitch + range + tune + fm_amt * x_fm, -10, +10)
f    = 261.6256 * 2^V                    // Hz(COM-03)
dphi = min(f / fs, 0.5)                  // 位相増分。サンプルレート依存はここだけ

// 3. パルス幅
pw_eff = clamp(clamp(pw,0.02,0.98) + pwm_amt * x_pwm / 10, 0.02, 0.98)

// 4. 波形(現在の phase から計算してから位相を進める)
saw   = 4 * (2*phase - 1)
pulse = (phase < pw_eff) ? +4 : -4
x     = phase<0.25 ? phase : (phase<0.75 ? 0.5-phase : phase-1)
tri   = 20 * x                           // 0→+5(p=0.25)→-5(p=0.75)→0
sine  = 5 * sin(2π * phase)

// 5. 状態更新
phase = phase + dphi;  if phase >= 1.0: phase -= 1.0      // dphi ≤ 0.5 なので1回の減算で足りる

// 6. 出力(各出力が NaN/∞ なら 0、COM-12)
```
- ステップ `n` の出力は「`n` 回目の位相更新前」の位相から計算する。同期なしで入力が一定なら `phase[n] = n·dphi mod 1`。
- `sync` が立ち上がったサンプルでは位相0の出力が書かれ、次のステップは `dphi` から進む。`sync` が high のまま続いても、立ち上がりのサンプルでのみ位相が戻る。
- ピッチ変化は階段状に周波数へ反映される(補間なし)。位相は常に連続で、ピッチ変更自体が位相を飛ばすことはない。
- 周波数クランプ: `V` を ±10 に制限して `f` は約0.2555 Hz 〜 267.9 kHz。上側は `dphi ≤ 0.5`(f ≤ fs/2)で上限が決まる。 [A]

**音質要件(機能再現と分離)**
- この仕様の波形は理想形(ナイーブ)で、ノコギリ・矩形・三角は折り返し雑音(エイリアシング)を含む。これは機能の誤りではなく音質の性質で、バンドリミット化は#3以降の選択とする。[A]
- 測定方法(参考。数値目標は根拠がないため固定しない): `fs=48000`、`pitch` 一定で `saw` を 2^16 サンプル取得し、Hann窓のFFTで基本波とその整数倍高調波を除くピークを「折り返し成分」として測り、基本波比(dB)を報告する。周波数を変えて(例: 440 Hz, 4 kHz, 10 kHz)比較する。

## 7. 共通規約との関係
- COM-01/02: 出力は ±5 V 以内で ±12 V を超えない(COM-02(3))。入力は範囲外でも黙って切り捨てず、`V` のクランプは周波数の安全範囲の制限であり波形電圧の切り捨てではない。
- COM-03: `f0 = 261.6256 Hz`。COM-04: `sync` はシュミット判定。COM-05/06: 1サンプル処理、出力は次ステップに接続先から見える。
- COM-07: 同一ステップの順序は sync → 周波数計算 → 波形生成 → 位相更新。「RESET後1 msのCLOCK無視」は CLOCK入力を持たないため該当しない。
- COM-09: 未接続時は §3 の値。COM-10/12/13/14: §5・§8・§4・§9 に記載。
- 固有: `sync` と `reset()` の区別(§5)。

## 8. 異常入力・境界・数値安定性
- 入力の NaN/±∞ は 0 V として扱う(COM-12)。パラメータの NaN/∞ は既定値。
- `pitch` が大きい: `V` を ±10 にクランプ。`dphi` は 0.5 を超えない(f=fs/2 のとき saw は -4,0,-4,0… になる)。
- `pitch` が小さい: V=-10 で f≈0.2555 Hz。位相は進み続け、停止しない(ゼロ周波数はない)。
- `pw` は 0.02〜0.98 にクランプし、矩形が常に一定値(DC)になることを避ける。`pwm` が大きくても `pw_eff` は同範囲に収まる。
- `phase` は double で `[0,1)` を保つ。`phase >= 1` のとき減算するため `phase=1.0` は出力されない。
- 出力は `±0` と `-0` を同一視してよい。DCは出ない(saw/tri/sine は一周期平均0、pulse は `pw_eff≠0.5` で平均が0でない)。

## 9. 保存・復元・版互換
- 保存対象(COM-14): パラメータ5個、`phase`(double)、`sync_state`、`spec_id=MOD-OSC-001`、仕様版 0.1。PRNGは使わないため保存しない。
- 復元後は、同じ入力列に対し保存しなかった場合とビット同一の出力列を返す(TV-MOD-OSC-001-09)。`phase` を float32 へ丸めて保存してはならない。
- 版移行: 現時点で旧版はない。

## 11. 未確認・保留事項
- 原機のレンジ5段ごとの周波数範囲、Tuneの幅(版差あり)、同期・リセット条件はDB未確認(M001 unknowns)。レンジとチューンの範囲、`sync` の仕様は[A]。#3で見直し可。
- 三角・正弦の「切れ込み」など原機の非理想性とアナログドリフトは再現しない。
- バンドリミット(PolyBLEPなど)の採否、リニアFM、PWM入力の感度(10 V=全幅)は#3で見直し可。
- 出力電圧の公称値(F-001-016は典型値)は保証値でなく、#3で正規化レベルを変える可能性がある。
