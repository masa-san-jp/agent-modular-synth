# 機能分類と仕様対象一覧(カタログ)

版: 0.1 / 2026-11-13。共通規約は [common.md](common.md)、テンプレートは [_template.md](_template.md)。
これは**採用モジュール一覧ではない**(#3で最終選定する)。調査(拡張DB・精査済みDB)で根拠が得られ、独立実装者が再現できる範囲を仕様化する。

## 状態の定義
| 状態 | 意味 |
|---|---|
| specified | 仕様化済み(全必須項目が埋まり、検証例がある) |
| deferred | 根拠不足で保留。不足内容を仕様IDの §11 に記録 |
| out_of_scope | 対象外(理由を記載) |

## 機能分類と対象
各分類は「共通機能(複数機種で共通)」と「機種固有・方式差」を分け、後者は各仕様の §2 に代替方式として残す。

| 仕様ID | 名称 | 分類 | 状態 | 共通機能(根拠の主なリファレンス) | 方式差・固有 |
|---|---|---|---|---|---|
| MOD-OSC-001 | VCO | 発振・音源 | specified | 1V/oct、波形選択、同期(M001, REF-001-005, F-005-013) | アナログ核の非線形・ドリフトは扱わない |
| MOD-NSE-001 | ノイズ源 | 発振・音源/ノイズ | specified | 白色ノイズ(REF-005-007, REF-010-010) | 色付き(ピンク)は後続 |
| MOD-FLT-001 | ローパスフィルタ(ラダー系) | 音色加工 | specified | カットオフCV、共振(M004, REF-001-006) | SVF/多モードは後続 |
| MOD-AMP-001 | VCA | 増幅・ミックス | specified | 利得CV×入力(M005) | 指数/線形の差を明記 |
| MOD-MIX-001 | ミキサー | 増幅・ミックス | specified | 複数入力の加算とレベル(REF-001-009) | |
| MOD-UTL-001 | アッテヌバータ/オフセット | 入出力・ユーティリティ | specified | 定数・反転・減衰(REF-002-002ほか) | |
| MOD-ENV-001 | ADSRエンベロープ | 変調 | specified | gate駆動、retrigger(M002, REF-001-007) | 区分的な形状(指数/線形)は仕様で固定 |
| MOD-LFO-001 | LFO | 変調 | specified | 低周波発振、波形(REF-001-008) | |
| MOD-FNC-001 | スルー/関数発生器 | 変調 | specified | rise/fall、サイクル、EOR/EOC(REF-002-002 Maths) | Mathsの全機能は含まない |
| MOD-CLK-001 | クロック | クロック・シーケンス | specified | BPM→パルス(M006周辺, REF-007-005) | |
| MOD-CLK-002 | クロック分周 | クロック・シーケンス | specified | 分周、リセット(REF-001-010) | 倍化は後続 |
| MOD-SEQ-001 | ステップシーケンサ | クロック・シーケンス | specified | step/reset、gate+CV(M006, REF-003-007) | 保存メモリ構造は含まない |
| MOD-RND-001 | サンプル&ホールド/ランダム | ランダム・論理 | specified | S&H、ノイズ正規化(REF-004-009, REF-002-003) | 乱数アルゴリズムはCOM-11に固定 |
| MOD-LGC-001 | 論理・比較 | ランダム・論理 | specified | AND/OR/NOT/比較(gate論理) | |
| MOD-DLY-001 | ディレイ | 時間系 | specified | 遅延時間、フィードバック(REF-002-004) | 補間・変調は仕様で固定 |
| MOD-IO-001 | オーディオ出力 | 入出力・計測 | specified | マスター出力、出力保護(安全性は#3) | 実機のD/A変換は含まない |
| MOD-IO-002 | MIDI-CV | 入出力・計測 | specified | note→pitch/gate/velocity(M003, REF-005-008) | MPE等は後続 |
| MOD-IO-003 | メーター/スコープ | 入出力・計測 | specified | 値の読出し(エージェントの状態確認用) | 描画は含まない |

## 仕様化を保留・対象外とするもの
| 候補 | 状態 | 理由 |
|---|---|---|
| 波形整形(ウェーブフォルダ等) | deferred | 調査DBに挙動の根拠が不足 |
| リバーブ/コーラス等の空間系 | deferred | 公開資料にアルゴリズム記述が乏しい(T-017 SPACE FXはパラメータ範囲のみ) |
| 複雑オシレータ(Plaits系エンジン) | deferred | ソースは公開(MIT)だが、アルゴリズム記述の根拠が不足。ライセンスは個別確認 |
| ピッチ量子化 | deferred | スケール定義・丸め規則の根拠が不足 |
| リングモジュレータ | deferred | 二次資料のみ(T-014 M-150)。乗算でMOD-AMP-001に近い |
| ヴォコーダ | deferred | 根拠不足 |
| アナログ回路の完全な音響再現 | out_of_scope | 機能再現を対象とする。非公開の内部回路は推測で断定しない |
| 電源・ラックバス・筐体規格 | out_of_scope | ハードウェア固有。仮想環境では不要 |
| S-trig(GND短絡型)の電気的モデル | out_of_scope | COM-04。互換モジュールは後続 |
