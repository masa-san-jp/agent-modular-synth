# MOD-SAT-001 サチュレータ(歪み・波形整形)

## 1. 目的と範囲
- 目的: 入力 `in` を増幅(`drive`)してから、波形を曲げる関数に通し、倍音を足す。音を太く・荒くする(キックや低音を重くする、など)。1サンプルごとの状態を持たない純関数。
- 含む: 入力の増幅(`drive`、CVで変調可)、3つの曲げ方(ソフト・ハード・フォールド)、非対称(`bias`)、原音との混ぜ具合(`mix`)、出力の音量(`level`)、±12 Vクリップ。
- 含まない: 特定の機種・回路の再現(真空管、ダイオード、テープなど)、オーバーサンプリングやバンドリミット(エイリアス抑制)、周波数に依存する歪み(前後のフィルタ)、内部状態を持つ歪み(ヒステリシスなど)。

## 2. 由来と抽象化
| ID | 種別 | 記述 | 根拠 |
|---|---|---|---|
| S-01 | [R] | 音声は約±5 V、CVは0〜10 Vまたは±5 Vが典型。生成電圧は±12 Vを超えない | F-005-009(high), F-005-010(high) |
| S-02 | [R] | 有限入力でNaN/∞を出しうるモジュールは0を返す | F-005-014(high) |
| S-03 | [A] | 本仕様は特定の原機の再現ではない。調査DBには歪み・波形整形の挙動の根拠がなく(catalog.md で保留としていた)、オーナーの指示(plans/decisions.md DEC-019)により、設計仮定だけで定義する | DEC-019 |
| S-04 | [A] | 曲げ方は、数式で一意に決まる3種に固定する: ソフト(双曲線正接 tanh)、ハード(±1 でのクリップ)、フォールド(±1 で折り返す三角形の関数)。いずれも入力が小さいとき傾き 1 の直線に一致する | 設計仮定 |
| S-05 | [A] | 基準レベルは ±5 V = ±1(S-01 の音声レベル)。関数の出力 ±1 を ±5 V に戻す | F-005-009 |
| S-06 | [A] | `drive` は dB(0〜36 dB)。CV感度は 3 dB/V(加算型)。`bias` は関数の入力に足す定数(非対称にして偶数次の倍音を足す)で、入力 0 V のとき出力が 0 V になるよう、関数の `bias` での値を引く | 設計仮定 |
| S-07 | [A] | バンドリミットをしない(折り返し雑音を含む)。MOD-OSC-001 と同じ方針(catalog.md の「扱わない」) | 設計仮定 |

方式選択: `out = clamp((1−mix)·in + mix·5·level·(f(g·in/5 + bias) − f(bias)), −12, +12)`、`g = 10^(drive/20)`。状態を持たない(同じ入力とパラメータなら、同じ出力)。

## 3. ポート
| 名前 | 方向 | 型 | ch | 単位 | 範囲 | 更新周期 | 未接続時 |
|---|---|---|---|---|---|---|---|
| in | in | audio | 1〜16(主入力。N を決める。§7) | V | 任意の有限値 | サンプル毎 | 0 V(出力は 0 V) |
| drive_cv | in | cv | 1〜16(副入力。§7) | V(3 dB/V) | 任意の有限値 | サンプル毎 | 0 V(変調なし) |
| out | out | audio | N(§7) | V | -12 〜 +12 | サンプル毎 | (出力。未接続でも計算) |

ポリフォニー(COM-08): エンジン数 `N` は主入力 `in` のチャンネル数(未接続なら1)で、`out` は `N` チャンネル。チャンネルごとに独立に同じ式を適用する(パラメータは全チャンネル共通。§7)。

## 4. パラメータ
| 名前 | 単位 | 範囲 | 既定値 | 変調 | 更新タイミング | 補間 |
|---|---|---|---|---|---|---|
| drive | dB(関数に通す前の増幅) | 0〜36 | 12 | 可(加算型、COM-18): `drive_cv`(感度 3 dB/V)。有効値 `d = clamp(drive + 3·drive_cv, 0, 36)` | 次のステップ | なし(階段状) |
| bias | 無次元(関数の入力に足す定数。±1 = ±5 V 相当) | -1〜+1 | 0 | 不可 | 次のステップ | なし |
| mode | 列挙(0=ソフト、1=ハード、2=フォールド。整数型として扱う) | 0〜2。四捨五入後にクランプ(COM-13)。NaN/∞は既定0 | 0 | 不可 | 次のステップ | なし(切替で出力が段差を持つ) |
| mix | 無次元(0=原音のみ、1=歪ませた音のみ) | 0〜1 | 1 | 不可 | 次のステップ | なし |
| level | 無次元(歪ませた音に掛ける倍率) | 0〜1 | 1 | 不可 | 次のステップ | なし |

- 範囲外はクランプ(COM-13)。NaN/∞ のパラメータは既定値として扱う。[A]
- `drive` を上げると音量も上がる(関数の出力は ±5 V で頭打ち)。音量をそろえるには `level` を下げる。

## 5. 内部状態と初期化・リセット
- 状態変数: なし(出力は同じステップの入力とパラメータだけで決まる)。
- `reset()`: 影響なし(状態がないため)。パラメータ値は変えない(COM-10)。
- RESET入力ポート: 持たない。
- **ポリフォニー時**(COM-08): 状態を持たないため、エンジンごとの状態もない。`N` が変わっても引き継ぐ・破棄する状態はない。

## 6. 振る舞い
1サンプルの処理(COM-05/06)。演算は倍精度で行い、結果を float32 で出力する。
```
x  = in が finite ? in : 0                      // 未接続は 0 V
cv = drive_cv が finite ? drive_cv : 0
d  = clamp(drive + 3·cv, 0, 36)                 // dB
g  = 10^(d / 20)                                // 1 〜 約 63.1
s  = g·x/5 + bias                               // ±5 V を ±1 として、関数の入力へ
w  = 5 · level · ( f(s) − f(bias) )             // 入力 0 V のとき 0 V になるよう、f(bias) を引く
y  = clamp( (1 − mix)·x + mix·w, −12, +12 )
out = y
```
関数 `f`(`mode` で選ぶ):
```
mode 0 ソフト:     f(s) = tanh(s)
mode 1 ハード:     f(s) = clamp(s, −1, +1)
mode 2 フォールド: f(s) = | ((s − 1) mod 4) − 2 | − 1      // mod は結果が 0 以上 4 未満になる剰余
```
- フォールドは、`|s| ≤ 1` では `f(s) = s`、1 を超えると折り返す(`f(2) = 0`、`f(3) = −1`、`f(4) = 0`、`f(5) = 1`)。周期 4 の三角形。
- どの `mode` でも、入力が小さいとき(`|s| ≪ 1`、`bias = 0`)は `out ≈ g·in·level`(直線)。`drive = 0`、`mode = 1`、`|in| ≤ 5` なら `out = in`。
- サンプルレート依存の式はない(`fs` を使わない)。出力は同じステップの入力から決まる(モジュール内の遅延なし)。
- バンドリミットをしないので、高い音・強い `drive` では折り返し雑音が出る(S-07)。

## 7. 共通規約との関係
- COM-01/02: 入力は範囲外でも受け付ける。出力は ±12 V に制限する(生成電圧の上限)。
- COM-05/06: 1サンプル処理。COM-09: 未接続時 0 V。COM-12: 入力のNaN/∞は 0 V、出力はNaN/∞にならない。COM-13: パラメータのクランプと、`mode` の四捨五入。
- COM-07: 該当なし(イベント入力なし)。COM-14: 保存はパラメータのみ(§9)。
- COM-08(ポリフォニー): **主入力は `in`**。`N` = `in` のチャンネル数(未接続なら `N = 1`)、`out` は `N` チャンネル。**副入力は `drive_cv`**: 1チャンネルなら全エンジンへコピー、`N` より少なければ不足分は 0 V、未接続なら 0 V。パラメータは全チャンネル共通。
- COM-18: `drive_cv` は加算型で、感度 `k = 3 dB/V`(固定。パラメータではない)。

## 8. 異常入力・境界・数値安定性
- 入力 NaN/±∞ → 0 V として扱う。パラメータ NaN/∞ → 既定値。
- **置換カウンタ**(COM-12 の `nonfinite_count`): `in`、`drive_cv` の値が NaN/±∞ で 0 V に置換したとき、1チャンネル・1サンプルにつき1増やす。読むのは先頭 `N` チャンネルだけ。未接続の入力は数えない。出力は、有限の入力に対して常に有限(`tanh` とクリップと折り返しは ±1 に収まり、原音との混合は ±12 V にクランプする)なので、出力側の置換は起こらない。`reset()` で 0 に戻る。
- 過大入力: `g·x/5` が大きくても、`f` は ±1 に収まる。原音を混ぜる場合(`mix < 1`)は、混合後に ±12 V でクリップする。
- フォールドの剰余: 入力は有限で、`|s| ≤ 63.1·|x|/5 + 1`。倍精度の剰余で計算する。
- 0割り: 割り算は定数(5、20)だけ。

## 9. 保存・復元・版互換
- 保存対象(COM-14): パラメータ `drive`、`bias`、`mode`、`mix`、`level`、`spec_id=MOD-SAT-001`、仕様版 0.1。内部状態・PRNGはない。`nonfinite_count` は診断値で保存対象外(COM-12)。
- 復元後は、同じ入力列に対しビット同一の出力列を返す(状態がないためパラメータの一致だけで足りる。再現性の範囲は同一環境: DEC-009。`tanh` と `10^x` の値は実行環境の数学関数に依る)。
- 版移行: 初版(0.1)。旧版はない。

## 11. 未確認・保留事項
- 調査DBに根拠がなく、すべて設計仮定である(S-03)。実在の機種(ウェーブフォルダ、オーバードライブ)の挙動との比較はしていない。根拠が得られたら、曲げ方の追加・変更を検討する。
- バンドリミットをしないため、折り返し雑音が出る(S-07)。音質の目標(OPEN-006)が決まった時点で、オーバーサンプリングの要否を見直す。
- `drive` の範囲(0〜36 dB)、CV感度(3 dB/V)、基準レベル(±5 V)は初期値で、試聴して見直してよい。
