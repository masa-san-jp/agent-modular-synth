# MOD-DLY-001 ディレイ

## 1. 目的と範囲
- 目的: 音声入力を循環バッファに書き込み、設定した遅延時間だけ前の値を読み出して出力へ混ぜる。読み出した値の一部を書き込みへ戻す(フィードバック)ことで、繰り返し(エコー)を作る。1サンプルごとに「入力を読む→遅延出力を読む→バッファへ書く→出力」を行う。
- 含む: 遅延時間(手動+CV)、線形補間による小数サンプル遅延、フィードバック、ドライ/ウェットのミックス、±12 Vのクリップ。
- 含まない: ステレオ、テンポ同期、BBD特有のクロックノイズ・帯域制限、テープ式の劣化、フィードバック経路のフィルタ/ダンピング、ピンポン、遅延時間の平滑化(§11)、2秒を超える遅延。原機の音響特性は再現しない。

方式選択: 循環バッファ(長さ `L = round(2.0·fs) + 2`)から、書き込み前に読み出して遅延出力を得る。フィードバックはその読み出し値を入力に加えてバッファへ書く。代替: 3次補間(高域の減衰が小さい)、遅延時間の平滑化、フィードバック経路のローパス。

## 4. パラメータ
| 名前 | 単位 | 範囲 | 既定値 | 変調 | 更新タイミング | 補間 |
|---|---|---|---|---|---|---|
| time | 秒 | 0〜2.0(有効値は 1/fs〜2.0 にクランプ) | 0.25 | 可: `time_cv`(感度 0.1 秒/V)。有効値 `t = clamp(time + 0.1·time_cv, 1/fs, 2.0)` | 次のステップ | なし(読み出し位置が即座に変わる。§8) |
| feedback | 無次元(フィードバック比) | 0〜1 | 0.0 | 不可 | 次のステップ | なし |
| mix | 無次元(0=ドライのみ、1=ウェットのみ) | 0〜1 | 0.5 | 不可 | 次のステップ | なし |

- 有限の範囲外値はクランプ(COM-13)。**NaN/∞のパラメータは既定値**(time=0.25, feedback=0.0, mix=0.5)を使う(COM-12)。例: `time=+∞` は 0.25(2.0 sにクランプではない)、`mix=+∞` は 0.5。[A]
- **CV感度の形(COM-18)**: 加算型 `t = clamp(time + k·time_cv, 1/fs, 2.0)`。感度 `k = 0.1 秒/V` は**固定値**でパラメータにしない(S-07)。
- 意味と単位: `time` は秒(CVでなく値そのもの)。`feedback` と `mix` は無次元の**倍率(比)**で、電圧ではない(`feedback` はウェットのうち書き戻す比、`mix` は `out = (1−mix)·x + mix·yd` の混合比。0=ドライのみ、1=ウェットのみ)。
- 遅延サンプル数 `d = clamp(t·fs, 1, 2.0·fs)`(小数)。

## 5. 内部状態と初期化・リセット
- 状態変数:
  - `buf[0..L-1]`(float、初期値すべて 0.0)、`L = round(2.0·fs) + 2`(fs=48000で96002)。
  - `w`(書き込み位置、整数、初期値 0)。
- `reset()`: `buf`のすべてを0、`w=0`。パラメータは変えない。PRNGは使わない。
- RESET入力ポート: なし(該当なし)。
- `fs`変更時: COM-05に従い、新しい`fs`で`L`を再計算して`buf`を確保し直し、全状態を0に初期化する。

## 6. 振る舞い
1サンプルの処理:
```
// 1) 入力を読む(未接続・NaN・inf は 0)
x, tcv
// 2) 有効値
// パラメータのNaN/∞は既定値(time=0.25, feedback=0, mix=0.5)。その後クランプ
t   = clamp( clamp(finite_or(time,0.25),0,2.0) + 0.1*tcv , 1/fs , 2.0 )
fb  = clamp(finite_or(feedback,0), 0, 1);   m = clamp(finite_or(mix,0.5), 0, 1)
d   = clamp( t*fs , 1 , 2.0*fs )            // 遅延サンプル数(小数)
i   = floor(d);   fr = d - i
// 3) 遅延出力を読む(書き込みより前)
yd  = buf[(w - i) mod L]*(1 - fr) + buf[(w - i - 1) mod L]*fr
// 4) バッファへ書く、書き込み位置を進める
buf[w] = clamp(x + fb*yd, -12, +12)
w      = (w + 1) mod L
// 5) 出力
out = clamp((1 - m)*x + m*yd, -12, +12)     // 非有限なら 0 (COM-12)
```
- 時間の進み: 書き込みが1サンプルずつ進み、`d`サンプル前の書き込み値が`yd`になる。`d=10`(整数)なら、サンプル`n`に入った値が`n+10`で出る(`buf[w]`は読み出し後に書かれるため、`d=1`で1サンプル遅れ、同サンプルは参照しない)。
- 小数遅延: `d=2.5`なら、2サンプル前と3サンプル前を等しく混ぜる。
- フィードバック: `yd`(`d`サンプル前の値)を`fb`倍して入力に足す。`fb=1`は繰り返しが減衰しない(クリップで頭打ち)。
- サンプルレート依存: `d = t·fs`。バッファ長`L = round(2.0·fs)+2`。サンプル数としての遅延は`fs`に比例し、秒としての遅延は不変。

## 7. 共通規約との関係
- COM-01: `in`/`out`は`audio`、`time_cv`は`cv`。型違い接続は許可。
- COM-02/12: 出力と書き込み値は±12 Vでクリップ。非有限入力は0 V、パラメータのNaN/∞は既定値(§4)。
- COM-05/06: 1サンプル1ステップ。パラメータ変更は次ステップから。モジュール内の遅延は最小1サンプル(S-10)で、ケーブル遅延(COM-06)とは別に加わる。
- COM-09: 全入力が未接続で0 V。normallingなし。
- COM-10: 初期状態・reset()は§5。
- COM-13/18: 変調可能パラメータは`time`のみ(加算型 `clamp(param + k·cv)`、k=0.1秒/V固定)。
- COM-14: 保存対象は§9。
- COM-07(同時イベント)、COM-11(乱数)は使わない。
- COM-08(ポリフォニー): モノを正本とし、ポリ入力時はチャンネルごとに独立のバッファ`buf`と`w`を持ち、同じ式を適用する。`time_cv`が1チャンネルなら全チャンネルにコピー、Nチャンネルなら対応(COM-08)。メモリはチャンネル数に比例する。

## 8. 異常入力・境界・数値安定性
- 入力のNaN/∞は0 V。バッファへ書く値は±12 Vでクリップされるため、内部は常に有限。
- 有限の範囲外パラメータはクランプ(`time`は0〜2.0、`feedback`と`mix`は0〜1)。NaN/∞のパラメータは既定値(TV-13)。`time`=0や、`time_cv`で負側へ振れた場合は最小遅延1サンプル(`t=1/fs`)。2秒を超える設定は2.0秒。
- 遅延時間の変化: 補間・平滑化なしで読み出し位置が変わる。`time_cv`が連続的に変化する場合は読み出し位置が滑らかに動き、ピッチが変わる。`time`パラメータの階段状の変化は、読み出し位置の不連続(クリック)を生む。
- フィードバック1.0での発散: 書き込み値が±12 Vで頭打ちになり、出力は±12 Vを超えない(TV-06)。
- ゼロ割り: なし。`mod L`は整数演算。負の添字は`mod`で正に折り返す。
- ドライ信号の過大入力: 入力が±12 Vを超える場合、`mix=0`でも出力は±12 Vでクリップされる(TV-07)。
- ウェット信号は`buf`の中身(±12 V以内)だけなので、`mix=1`なら常に±12 V以内。

## 9. 保存・復元・版互換
- 保存対象: ①パラメータ3個(`time`, `feedback`, `mix`)、②内部状態: `buf[0..L-1]`の全要素と`w`(および`fs`、`L`は`fs`から導かれる)、③PRNG状態: なし、④`spec_id=MOD-DLY-001`と版`0.1`。
- 復元同値性(COM-14): 保存直後から復元したモジュールは、同じ入力列に対し、保存しなかった場合とビット同一の出力列を返す(§10 TV-11)。`buf`の全要素と`w`を保存することで満たす(保存データは`L`個の数値を含み、`fs=48000`で96002個)。
- 版移行: 初版のため該当なし。`fs`が保存時と異なる場合は復元せず初期化する(COM-05の全再初期化と整合)。

音質要件(機能再現とは別。数値目標は固定しない):
- 補間の高域損失: 線形補間(S-08)は小数遅延で高域が減衰する。測定方法: `d`の小数部を0.5に設定し、`mix=1`、`feedback=0`で白色ノイズ(COM-11 PRNG、seed=1)を入力して、窓長 8192点のハン窓FFTで周波数応答を測り、整数遅延(小数部0)との差を記録する。許容は#3で決める。
- 遅延時間の変調: `time_cv`にLFOをつなぐとピッチが揺れる(ドップラー効果に似る)。揺れの深さはCVの傾き(0.1 秒/V)と変化速度で決まる。測定方法: 1 kHz正弦波を入力し、CVを 1 Hz・振幅 0.005 Vで揺らしたときの出力周波数の変動幅を記録する。
- フィードバック経路は無加工(ローパスなし)のため、繰り返しが減衰しにくく金属的に聞こえうる。ダンピングの要否は#3で決める。
