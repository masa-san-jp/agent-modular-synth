# MOD-LFO-001 LFO(低周波オシレータ)

## 1. 目的と範囲
- 目的: 周波数パラメータと1 V/oct の `rate` CV から位相の増分を決め、位相アキュムレータを1サンプルずつ進めて、5つの双極波形(ノコギリ・反転ノコギリ・三角・正弦・矩形)を同時に出力する。`reset` 入力の立ち上がりで位相を0へ戻す。
- 含む: 5波形同時出力、連続な周波数パラメータ(0.005〜4500 Hz)、1 V/oct の周波数CV、位相リセット、深さ(出力振幅比)。
- 含まない: 原機の3段レンジスイッチ(連続パラメータに抽象化)、単極出力への変換(MOD-UTL-001 のオフセットで行う)、クロック同期(BPM同期)、位相オフセット、ランダム波形(MOD-RND-001)、アナログの非理想性。

## 3. ポート
| 名前 | 方向 | 型 | ch | 単位 | 範囲 | 更新周期 | 未接続時 |
|---|---|---|---|---|---|---|---|
| rate | in | pitch | 1 | V(1 V/oct) | 任意の有限値(`cv_amt` 倍して±30 octにクランプ後、周波数を 0.005〜4500 Hz にクランプ) | サンプル毎 | 0 V(`freq` のまま) |
| reset | in | trigger | 1 | V | 任意の有限値(COM-04のシュミット判定) | サンプル毎 | 0 V(リセットなし) |
| saw | out | cv | 1 | V | -4·depth 〜 +4·depth | サンプル毎 | (出力。未接続でも計算) |
| saw_inv | out | cv | 1 | V | -4·depth 〜 +4·depth | サンプル毎 | (同上) |
| tri | out | cv | 1 | V | -4·depth 〜 +4·depth | サンプル毎 | (同上) |
| sine | out | cv | 1 | V | -4·depth 〜 +4·depth | サンプル毎 | (同上) |
| square | out | cv | 1 | V | -4·depth または +4·depth | サンプル毎 | (同上) |

ポリフォニー: COM-08の初期方針により1チャンネルを正本とし、複数チャンネル時はチャンネルごとに独立の位相状態を持つ。

## 4. パラメータ
| 名前 | 単位 | 範囲 | 既定値 | 変調 | 更新タイミング | 補間 |
|---|---|---|---|---|---|---|
| freq | Hz | 0.005 〜 4500 | 2.0(120 BPM、COM-03の基準) | 可(指数型、COM-18): `rate` 入力で `eff = freq·2^(cv_amt·rate)` | 次のステップ | なし(階段状。位相は連続) |
| cv_amt | oct/V | -1.0 〜 +1.0 | 1.0 | `rate` 入力の感度 k(指数型の感度。単位 oct/V) | 次のステップ | なし |
| depth | 比(倍率。出力電圧に掛ける無次元の係数で、V値ではない) | 0.0 〜 1.0 | 1.0 | 不可 | 次のステップ | なし |

- 範囲外はクランプ(COM-13)。NaN/∞ のパラメータは既定値として扱う。[A]
- CV感度(COM-18): `rate` は**指数型**(`f = freq·2^(k·rate)`、`k = cv_amt` の単位は oct/V)。加算型の変調はない。
- 乱数は使わないため `seed` は持たない。

## 5. 内部状態と初期化・リセット
- 状態変数:
  - `phase`: double、範囲 [0,1)、初期値 0.0。
  - `reset_state`: 0/1(`reset` 入力のシュミット状態)、初期値 0。
- `reset()`: `phase = 0.0`、`reset_state = 0`。パラメータは変えない(COM-10)。
- RESET入力ポート `reset`: 立ち上がりで `phase = 0.0` のみ。`reset_state` は通常のシュミット判定で更新され、パラメータには触れない。`reset()` と異なり、保存状態のうち `phase` だけが変わる。

## 6. 振る舞い
1サンプルの処理(COM-05/06/07):
```
x_rate, x_reset = 各入力(未接続は0、finite でなければ 0)

// 1. reset(イベント)を最初に処理
if schmitt(reset_state, x_reset) == rising:  phase = 0.0

// 2. 周波数
fr  = clamp(freq, 0.005, 4500)                       // NaN/∞ は 2.0
e   = clamp(clamp(cv_amt,-1,1) * x_rate, -30, +30)   // oct
f   = clamp(fr * 2^e, 0.005, 4500)                   // Hz
dphi = min(f / fs, 0.5)                              // fs 依存はここだけ

// 3. 波形(現在の phase から)
q     = (phase + 0.5) mod 1
sawv  = 4 * (2*q - 1)                                // p=0 で 0、p→0.5 で +4 まで上昇、p=0.5 で -4 へ跳ぶ
x     = phase<0.25 ? phase : (phase<0.75 ? 0.5-phase : phase-1)
tri   = 16 * x                                       // 0→+4(p=0.25)→-4(p=0.75)→0
sine  = 4 * sin(2π * phase)
sq    = (phase < 0.5) ? +4 : -4
d     = clamp(depth, 0, 1)                           // NaN/∞ は 1.0
saw=d*sawv; saw_inv=-d*sawv; tri=d*tri; sine=d*sine; square=d*sq

// 4. 状態更新
phase = phase + dphi;  if phase >= 1.0: phase -= 1.0

// 5. 出力(NaN/∞なら 0)
```
- n 番目の出力は、更新前の位相から計算する。リセットなしで入力が一定なら `phase[n] = n·dphi mod 1`。`reset` が立ち上がったサンプルでは位相0の出力が書かれる。`reset` が high のまま続いても、立ち上がりのサンプルでのみ戻る。
- 周波数CVの変化は階段状に周波数へ反映され、位相は常に連続(リセット時を除く)。
- サンプルレート依存式: `dphi = f / fs`、周期は `fs / f` サンプル。`f` が大きく `dphi = 0.5`(f = fs/2)に達する場合は `fs=48000` で 24 kHz だが、`freq` 上限4500 Hz のため、`f` が最大の4500 Hz のとき `dphi = 4500/fs` は `fs > 9000 Hz` では 0.5 未満で、`fs = 9000 Hz` ちょうどで 0.5 に届き(`f=4500 Hz`のとき)、`fs < 9000 Hz` でクランプが効く(`fs` が小さいときのみ有効な保護)。
- 原機のレンジ切り替え時の周波数ジャンプは再現しない(連続パラメータのため)。

**音質要件(機能再現と分離)**
- 波形は理想形(ナイーブ)。LFO帯域(0.005〜50 Hz)では折り返しは問題にならない。数kHz 設定時のノコギリ・矩形のエイリアシングは音質の問題で、機能とは別に扱う。測定方法(数値目標は固定しない): `fs=48000`、`freq=4000` で `saw` を 2^16 サンプル取得しHann窓FFTで高調波を除くピークの基本波比(dB)を報告する。

## 7. 共通規約との関係
- COM-03: `f = f0·2^V` の `f0 = 2 Hz`(LFO基準)。本仕様では COM-18 の指数型 `f = freq·2^(cv_amt·rate)` で書く。`rate = 0 V` で 2 Hz になるのは**既定パラメータのとき(`freq = 2.0`)だけ**で、`freq` を変えれば `rate = 0 V` の周波数は `freq` になる(`f0 = 2 Hz` は `freq` の既定値)。COM-04: `reset` はシュミット判定。COM-05/06: 1サンプル処理・1サンプル遅延(接続時)。
- COM-07: 処理順は reset → 周波数 → 波形 → 位相更新。「RESET後1 msのCLOCK無視」はCLOCK入力がないため該当しない。
- COM-02: 出力は ±4 V 以内(±12 Vを超えない)。COM-09: 未接続時は §3。COM-12: NaN/∞を0 Vとして扱う。COM-13/14: §4・§9。
- 固有: 出力は双極で、単極(0〜10 Vなど)への変換は MOD-UTL-001 で行う。

## 8. 異常入力・境界・数値安定性
- 入力のNaN/±∞は0 V。パラメータのNaN/∞は既定値。
- 周波数: `fr` を 0.005〜4500 Hz に、`e` を ±30 oct にクランプしてから乗算するため、オーバーフローしない。最終 `f` も同範囲にクランプ。`freq=0` や負値は 0.005 Hz になる(停止しない)。
- `phase` は `[0,1)`。浮動小数点の丸めで `phase=1.0` にならないよう、加算後に `>= 1` で減算する。
- 超低周波(0.005 Hz)では周期 200 秒。`dphi=1.04e-7`(fs=48000)で、double位相が必須。
- 出力にDC: 全波形は一周期平均0(depth に比例)。
- `depth=0`: 全出力0(位相は進む)。

## 9. 保存・復元・版互換
- 保存対象(COM-14): パラメータ3個、`phase`(double)、`reset_state`、`spec_id=MOD-LFO-001`、仕様版 0.1。PRNGなし。
- 復元後は、同じ入力列に対しビット同一の出力列を返す(TV-MOD-LFO-001-10)。
- 版移行: 現時点で旧版はない。
