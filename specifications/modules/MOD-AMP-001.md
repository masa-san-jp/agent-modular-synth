# MOD-AMP-001 VCA(電圧制御アンプ)

## 1. 目的と範囲
- 目的: 2系統の音声入力をレベルで減衰して加算し、制御電圧(手動ゲイン+CV1+CV2)で決まる利得を掛けて出力する。入力から出力まで、そのサンプルの値だけで決まる(内部状態なし)。
- 含む: 線形/指数の2種の利得カーブ(`response`で選択)、手動ゲイン、2系統のCV、入力2個・出力の減衰、音声レートのCVによる振幅変調(AM)。
- 含まない: 利得1を超える増幅(過大CVは利得1で飽和)、AC結合、ローパスゲート的な周波数特性、ドライブ(過入力の飽和)、ステレオ/パン。実機の回路特性(温度・ノイズ・貫通漏れ)は再現しない。

方式選択: 利得を `x`(CVの和)にクランプしてからカーブ(線形または指数)へ写す。実機は線形VCAと指数VCAが別製品(A-130/A-131)だが、1モジュールの`response`パラメータとして共通化した。代替: 線形のみ(M005準拠)、または別モジュール化。

## 4. パラメータ
| 名前 | 単位 | 範囲 | 既定値 | 変調 | 更新タイミング | 補間 |
|---|---|---|---|---|---|---|
| gain | 無次元(5 V相当の割合) | 0〜1 | 0.0 | 可: `cv1`(感度1/5 V)、`cv2`(感度`cv2_level`/5 V)を加算 | 次のステップ | なし(階段状。CVは補間なしでサンプル毎に反映) |
| in1_level | 無次元 | 0〜1 | 1.0 | 不可 | 次のステップ | なし |
| in2_level | 無次元 | 0〜1 | 1.0 | 不可 | 次のステップ | なし |
| cv2_level | 無次元 | 0〜1 | 1.0 | 不可 | 次のステップ | なし |
| out_level | 無次元 | 0〜1 | 1.0 | 不可 | 次のステップ | なし |
| response | 列挙(0=線形, 1=指数) | 0 または 1(それ以外は0として扱う) | 0 | 不可 | 次のステップ | なし(切替で階段状に変化) |

- 範囲外の数値パラメータはクランプ。NaNのパラメータは既定値を使う。[A]
- 補間なしなので、`gain`の急変は出力に階段状の変化(ジッパーノイズ)を与える。これは機能仕様どおり。平滑化の要否は#3で決める([A]、§11)。

## 5. 内部状態と初期化・リセット
- 状態変数: なし(出力はそのサンプルの入力とパラメータだけで決まる。前サンプルを参照しない)。
- `reset()`: 何もしない(状態がないため、リセット前後で同じ入力に同じ出力を返す)。
- RESET入力ポート: なし(該当なし)。
- `fs`変更時: 影響なし(サンプルレート依存の式がない)。

## 6. 振る舞い
1サンプルの処理:
```
// 1) 入力を読む(未接続・NaN・inf は 0)
in1, in2, cv1, cv2
// 2) 利得(状態更新はなし)
x  = clamp( gain + (cv1 + cv2_level * cv2) / 5 , 0, 1 )
g  = (response == 1) ? (1000^x - 1) / 999 : x
// 3) 出力
y   = (in1_level * in1 + in2_level * in2) * g * out_level
out = clamp(y, -12, +12)           // 非有限なら 0 (COM-12)
```
- 線形(`response=0`): `g = x`。CV 0〜5 Vで利得0〜1に比例(S-01)。`cv1`に音声レートの信号をつなぐとAM(リングモジュレータに近い単極動作。入力`cv1<0`の区間は利得0)。
- 指数(`response=1`): `g = (1000^x − 1)/999`。x=0.5で0.03065(-30.3 dB)、x=0.2で0.002984(-50.5 dB)。
- 加算順序: `in1_level·in1 + in2_level·in2`(この順)。
- サンプルレート依存: なし。

## 7. 共通規約との関係
- COM-01: `in1`/`in2`/`out`は`audio`、`cv1`/`cv2`は`cv`。型違い接続は許可。VCAの出力をCVとして使うこと(別VCAへの入力)も可能。
- COM-02/12: 出力は±12 Vでクリップ。入力の非有限値は0 V。
- COM-05/06: 1サンプル1ステップ。パラメータ変更は次のステップから。
- COM-09: 全入力が未接続で0 V。normallingなし。
- COM-10: 状態なしのため初期化・reset()は意味を持たない。COM-14(保存)は§9。COM-07(同時イベント)、COM-11(乱数)は使わない。
- COM-08(ポリフォニー): モノを正本とし、ポリ入力時は`in1`のチャンネル数Nで各チャンネルに同じ式を独立に適用する。`in2`/`cv1`/`cv2`が1チャンネルなら全チャンネルへコピー、Nチャンネルなら対応、不足分は0 V(COM-08)。

## 8. 異常入力・境界・数値安定性
- 入力のNaN/∞は0 V。結果が非有限になった場合も出力0(COM-12)。
- 範囲外パラメータはクランプ(`gain`、各`level`は0〜1)。`response`が0/1以外なら0(線形)。
- 過大CV: `x`は1でクランプされ、利得は1以上にならない(S-07)。負のCV(`x<0`)は利得0。
- 過大出力: 入力が大きい場合(例 20 V)、出力は±12 Vでクリップされる(COM-02)。
- 指数カーブの`1000^x`は`x`が0〜1に制限されているため、オーバーフローは起こらない。
- DC: DC入力はそのまま利得を掛けて通る(DC結合)。

## 9. 保存・復元・版互換
- 保存対象: ①パラメータ6個(`gain`, `in1_level`, `in2_level`, `cv2_level`, `out_level`, `response`)、②内部状態: なし、③PRNG状態: なし、④`spec_id=MOD-AMP-001`と版`0.1`。
- 復元同値性(COM-14): 状態を持たないため、パラメータを復元すれば同じ入力に同じ出力を返す。
- 版移行: 初版のため該当なし。

## 10. 検証例
基準実装(スクラッチの検証用Pythonのfloat64)で算出した。本モジュールは1回の乗算と加算のみで、float32実装との差は値の大きさ(最大12 V)に対する丸め誤差 7e-7 以下であり、許容誤差は絶対1e-6(COM-12の下限)とする。ただし指数カーブは`pow`の実装差があるため、TV-03は相対1e-6とする。

リセット・保存復元は該当しない: 内部状態を持たず(§5、frontmatter の stateful=false)、`reset()`は何もしない。同じ入力列には常に同じ出力列を返すことがTV-01〜09で確認できる。

音質要件(機能再現とは別。数値目標は固定しない):
- ジッパーノイズ: `gain`のステップ変化と`response`切替は平滑化しないため、不連続が出る。測定方法: 1 kHz正弦波を入力し、`gain`を0.0→1.0にステップさせ、出力のスペクトル(窓長 1024点)でステップ後のスペクトル広がりを記録する(許容は#3で決める)。
- AMの歪み: `cv1`に音声レートの信号を入れた場合、`cv1<0`の部分は0にクランプされるため片側整流的な高調波が出る。エイリアシングは入力と`cv1`の帯域積が `fs/2` を超えると生じる。測定方法: 周波数f1の正弦を`in1`、f2の正弦(0〜5 Vのオフセット付き)を`cv1`に入れ、出力スペクトルの `f1±f2` と折り返し成分のレベルを比較する。

## 11. 未確認・保留事項
- A-130-1の最大利得・飽和・過大CV時の挙動・既定ノブ値はDBにない(M005 unknowns)。最大利得1、クランプ、既定gain=0は設計仮定。利得1超(増幅)を許す案は#3で検討。
- 指数カーブの式 `(1000^x−1)/999` は設計仮定(DBに数式なし)。実機の指数VCA(A-131等)の特性を取り込む場合は#3で再定義。
- パラメータ変化の平滑化(ジッパー対策)の要否。
- `cv2_level`を0〜1(減衰器)としたが、-1〜+1(アッテヌバータ)とする選択肢は#3で検討。
- `response`をパラメータで統合したが、別モジュールに分ける案もある。
