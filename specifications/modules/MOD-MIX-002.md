# MOD-MIX-002 ミキサー卓(8チャンネル)

## 1. 目的と範囲
- 目的: 8つの入力を、チャンネルごとの音量・左右の位置(パン)・ミュート・ソロ・センドでまとめ、左右2つの出力とセンド出力に出す。あわせて、**各チャンネルと出力の音量と帯域ごとの量を測り、読出し値として返す**(人やエージェントが、音を聞かなくても配分を確かめて直せるようにする)。
- 含む: 8入力、チャンネルごとの音量・パン・ミュート・ソロ・センド量、全体の音量、ミュートと音量の切替時の平滑、ポリ入力の加算、±12 Vクリップ、チャンネルごと・出力・センドのメーター(ピーク、実効値、低・中・高の3帯域の実効値)。
- 含まない: イコライザ、コンプレッサ、ステレオ入力、センドの戻り専用の入力(戻りは空きチャンネルで受ける)、パンやセンドのCV変調、特定の機種の再現。

## 4. パラメータ

| window_ms | ミリ秒 | 10〜2000 | 300 | 不可 | 次のステップ。窓長 `W` は閉じ判定のたびに再計算(進行中の累積は保持) | なし |

- 範囲外はクランプ(COM-13)。NaN/∞ のパラメータは既定値として扱う。
- CV入力を持たないため、CV感度(COM-18)はない。乱数は使わない。

## 5. 内部状態と初期化・リセット
- 状態変数(すべて倍精度):
  - `g[i]`: チャンネルごとの、平滑後の音量。初期値は**目標値**(`t[i]`。§6)
  - `gm`: 平滑後の全体の音量。初期値は `master` の有効値
  - 帯域用のフィルタの状態: チャンネルごとに2つ(`lp200[i]`、`lp2k[i]`)、出力用に2つ。初期値 0
  - 窓の累積(サンプル数、チャンネルごと・出力・センドの最大と二乗和、帯域ごとの二乗和)。初期値 0
  - 読出し値(§3)。初期値 0
- `reset()`(COM-10): 上の状態をすべて初期値へ戻す。`g[i]` と `gm` は、その時点のパラメータから求めた目標値にする(初期値がパラメータに依る状態)。パラメータ値は変えない。置換カウンタも 0。
- RESET入力ポート: 持たない。
- **ポリフォニー時**(COM-08): 入力ごとに全チャンネルを加算して1つにする(§7)。エンジンは1組で、状態もモジュールに1組。

## 6. 振る舞い
1サンプルの処理(COM-05/06)。演算は倍精度で行い、出力は float32。`fs` はサンプルレート。
```
a   = 1 − exp(−1 / (0.005·fs))                 // 音量の平滑の係数(時定数 5 ms)
aL  = 1 − exp(−2π·200 / fs)                    // 帯域用のフィルタの係数
aH  = 1 − exp(−2π·2000 / fs)

// 1. 入力(ポリは全チャンネルを加算。未接続は 0 V)
x[i] = in_i の全チャンネルの和

// 2. 音量の目標値と平滑
anySolo    = solo[1..8] のどれかが 1
audible[i] = (mute[i] = 0) かつ (anySolo でない、または solo[i] = 1)
t[i]       = audible[i] ? level[i] : 0
g[i]       = g[i] + a·(t[i] − g[i])
gm         = gm + a·(master − gm)

// 3. チャンネルの信号(音量の後、パンの前)と、3つの出力
v[i]  = g[i]·x[i]
θ[i]  = (pan[i] + 1)·π/4
busL  = Σ v[i]·cos θ[i]
busR  = Σ v[i]·sin θ[i]
busS  = Σ v[i]·send[i]
L     = clamp(gm·busL, −12, +12)
R     = clamp(gm·busR, −12, +12)
SEND  = clamp(busS, −12, +12)                  // 全体の音量は掛けない

// 4. メーター(窓の累積)
チャンネル i: lp200[i] += aL·(v[i] − lp200[i]);  lp2k[i] += aH·(v[i] − lp2k[i])
              低域 = lp200[i]、中域 = lp2k[i] − lp200[i]、高域 = v[i] − lp2k[i]
              最大 = max(最大, |v[i]|)、二乗和に v[i]²、帯域ごとの二乗和に 低域²・中域²・高域²
出力:         m = (L + R)/2 を同じ2つのフィルタに通し、帯域ごとの二乗和を足す
              L と R のそれぞれについて、最大と二乗和
センド:       SEND の最大と二乗和
cnt += 1
W = max(1, floor(window_ms·fs/1000 + 0.5))
cnt ≥ W なら窓を閉じる: 読出し値を更新(実効値 = sqrt(二乗和 / cnt)、最大はそのまま)、windows += 1、累積を 0 に戻す(フィルタの状態は戻さない)
```
- パンが中央(`pan = 0`)のとき、左右とも `cos(π/4) = 0.70710678` 倍。左いっぱい(`pan = −1`)で左 1 倍・右 0 倍。
- ミュート・ソロ・音量の変更は、`g[i]` が時定数 5 ms で目標値へ近づくので、音が段差なく切り替わる。`n` サンプル後の `g` は、目標値との差が `exp(−n/(0.005·fs))` 倍に縮む。
- 同じステップの入力から出力が決まる(モジュール内の遅延なし。接続間の1サンプル遅延はCOM-06)。

## 7. 共通規約との関係
- COM-01/02: 入力は範囲外でも受け付ける。出力は ±12 V に制限する。
- COM-05/06: 1サンプル処理。COM-09: 未接続時 0 V。COM-10: `reset()` で状態を初期値へ(§5)。COM-12: 入力のNaN/∞は 0 V、出力はNaN/∞にならない。COM-13: パラメータのクランプ。COM-14: 保存(§9)。COM-17: 平滑の時定数は「時定数τ」(1/e になる時間)。
- COM-07: 該当なし(イベント入力なし)。COM-18: 該当なし(CV入力なし)。
- COM-08(ポリフォニー)の**例外**: このモジュールは集約を行う。各入力について、接続された全チャンネルを昇順に加算して1つの値にする(MOD-IO-001 と同じ: DEC-007)。主入力・副入力の区別はなく、出力 `L`・`R`・`SEND` は常に1チャンネル。

## 8. 異常入力・境界・数値安定性
- 入力 NaN/±∞ → 0 V として加算する。パラメータ NaN/∞ → 既定値。
- **置換カウンタ**(COM-12 の `nonfinite_count`): 各入力の全チャンネルを読み、NaN/±∞ で 0 V に置換した値1つにつき1増やす。未接続の入力は数えない。出力は ±12 V にクランプした有限値なので、出力側の置換は起こらない。`reset()` で 0 に戻る。
- 過大入力: 加算の結果が大きくても、出力は ±12 V でクリップする。メーターは、チャンネルについてはクリップ前の `v[i]`、出力についてはクリップ後の値を測る。
- 実効値の計算で二乗和が有限でなくなった場合(入力が極端に大きい)、その読出し値は 0 とする。
- 0割り: `cnt ≥ 1` のときだけ割る。

## 9. 保存・復元・版互換
- 保存対象(COM-14): 全パラメータ、`spec_id=MOD-MIX-002`、仕様版 0.1、内部状態(§5 の全部: `g[i]`、`gm`、フィルタの状態、窓の累積、読出し値、`windows`)。`nonfinite_count` は診断値で保存対象外(COM-12)。
- 復元後は、同じ入力列に対しビット同一の出力列と、同じ読出し値を返す(TV-MOD-MIX-002-16)。
- パッチ(data-contract)に保存するのはパラメータだけで、読み込むと `reset()` 後の状態から始まる(`g[i]` は目標値から)。
- 版移行: 初版(0.1)。旧版はない。

## 11. 未確認・保留事項
- パン・ミュート・ソロ・センド・メーターは、すべて設計仮定である(S-04)。実在のミキサーとの比較はしていない。
- 帯域の分け方(1次のフィルタ、200 Hz と 2000 Hz)は粗い。隣の帯域への漏れが大きい(TV-14)。配分の目安には足りるが、正確な周波数の分析には使えない。必要になったら、より急なフィルタか、帯域の数を増やすことを検討する。
- センドは1系統、戻りの専用入力はない。足りなければ、卓を2台置くか、版を上げて増やす。
- チャンネルの既定の音量(0.7)、窓の既定の長さ(300 ms)は初期値で、使ってみて見直してよい。
