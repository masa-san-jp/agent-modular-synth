# 曲調ごとの音作りの目安(音像を曲調に合わせる)

曲を書くエージェント(と人)のための目安。数値の目安は `demo/styles.mjs` にあり、`demo/mixcheck.mjs` で確かめる。

- このシンセは器で、音色を決めるのはパッチと楽譜(DEC-018)。同じモジュールでも、作り方しだいで曲調に合わない音になる。
- 2026-11-25 にオーナーから受けた指摘が出発点である。
  - アンビエント: 大きく金切り声のような旋律が耳障りで、ほかの音と調和していなかった。
  - チップチューン: 昔の音源の、低ビットの安っぽい音色が出ていなかった。

## 1. 確かめ方(`demo/mixcheck.mjs`)
```
npm run build
node demo/mixcheck.mjs demo/ambient.mjs
```
- 曲が `MIX`(曲調と、卓のチャンネルごとの役割)を持っていれば、チャンネルごとに次の 3 つを測り、目安から外れた所に印を付ける。
  - **大きさ**: 短期ラウドネス(EBU R128、3 秒)の最大。基準の役割との差 [LU] で比べる。まばらに鳴る音も、鳴った瞬間の大きさで比べられる。
  - **明るさ**: スペクトル重心 [Hz]。音の大きい所ほど重く数える。
  - **耳に刺さる帯域**: 2〜5 kHz のエネルギーの割合。
- **チャンネルの音の取り出し方**: 「全体 − そのチャンネルを消した全体」で取り出す。エンジンは毎回同じ計算をするので、引き算で正確に取れる。卓のセンドで送った響きは、元のチャンネルの音に含まれる。
- **書き出しの条件**: 出力の保護が効かない小さな音量(−20 dB)で、並列に書き出す。作業用のクラウドの環境(4 コア)で、1 曲 1.5〜3 分。
- **電圧で測らない理由**: 卓のメーター(`meter.read`)の電圧の実効値だけで配分を決めると、耳に聞こえる大きさと合わない。高い音、ノイズ、まばらな音は、電圧で見るより大きく聞こえる。アンビエントの鐘が突き刺さったのは、これが原因だった。

## 2. 曲調ごとの目安
大きさは、基準の役割との差 [LU]。明るさは、スペクトル重心 [Hz]。

### アンビエント(基準: 和音)
| 役割 | 大きさ | 明るさ | 作り方 |
|---|---|---|---|
| 和音(pad) | 0 | 120〜700 | 立ち上がり 0.5 秒以上、余韻を長く。少しずらした発振器を重ねて、低域通過でこもらせる |
| 旋律・鐘(lead) | −9〜−4 | 250〜750 | 音域は C4〜A5。正弦波か三角波、または低域通過で丸める。FM は整数倍の比で浅く。立ち上がり 20 ms 以上。強さの幅を狭く |
| 響き(fx) | −12〜−6 | 120〜800 | 暗く、量は多め。戻りのフィルタを元の音より下に |
| 質感(texture) | −14〜−8 | 100〜1500 | ノイズは共振のフィルタで帯域を絞る |
| 低い持続音(sub) | −12〜−7 | 30〜150 | 正弦波 1 つ |

### ミニマル(基準: 型 A)
| 役割 | 大きさ | 明るさ | 作り方 |
|---|---|---|---|
| 型(lead / counter) | 0 / −5〜−1 | 300〜1600 | 短い型をくり返し、フィルタの開き具合で変化をつける。型どうしは音域か左右でずらす |
| 響き(fx) | −10〜−5 | 200〜1500 | 付点 8 分のディレイ |
| 低音(bass) | −4〜−1 | 50〜400 | |
| キック(kick) | −5〜−1 | 40〜200 | 柔らかく短く |
| ハイハット(hats) | −11〜−6 | 3000〜9000 | 白色ノイズのままは鋭すぎる(重心 12 kHz)。低域通過で落とす |

### ヴェイパーウェイヴ(基準: 旋律)
| 役割 | 大きさ | 明るさ | 作り方 |
|---|---|---|---|
| 旋律(lead) | 0 | 250〜1500 | こもらせる。ビブラート |
| 和音・エレピ(pad / keys) | −6〜−2 | 150〜1000 | メジャー 7th 系。エレピは正弦波を正弦波で FM |
| 低音・キック・スネア | −7〜−2 | 低音 40〜250、キック 40〜200、スネア 700〜4500 | スネアは響きに多め |
| ハイハット(hats) | −13〜−8 | 2500〜9000 | |
| 響き(fx) | −11〜−6 | 200〜1500 | |

共通: テープの揺れ(遅い LFO で、音程をわずかに揺らす)。全体の高域を削る。

### チップチューン(基準: 旋律)
| 役割 | 大きさ | 明るさ | 作り方 |
|---|---|---|---|
| 旋律・分散和音(lead / arp) | 0 / −7〜−3 | 400〜6000 | パルス幅 12.5 / 25 / 50 %。フィルタを使わない |
| 低音(bass) | −6〜−2 | 60〜600 | 三角波。鳴っている間は同じ大きさ |
| キック・ノイズ(kick / perc) | −7〜−3 / −8〜−4 | 60〜2000 / 1500〜9000 | |

**粗さ**: 全体をサンプル&ホールド(MOD-RND-001)に通し、約 9 kHz ごとに値を取り込む。サンプリング周波数を落とすのと同じで、折り返しの雑音と段々が乗る。
- 叩く信号: 発振器のパルス波。音程は、アッテヌバータ(MOD-UTL-001)の固定の電圧で決める(5.1 V ≒ 9 kHz)。
- 左右: 中央にまとめる。響きは使わない。

### テクノ(基準: キック)
キックがいちばん大きい。低音はキックを避けて刻む。大きさの目安は `demo/styles.mjs`。

### トランス(基準: キック)
| 役割 | 大きさ | 明るさ | 作り方 |
|---|---|---|---|
| 主旋律(lead) | −3〜0 | 800〜6000 | 鋸歯 3 本を少しずつずらして重ね、フィルタを通さない。高い音域(A5 より上)で、遅れてかかるビブラート |
| ライザー(riser) | −8〜−3 | 500〜8000 | 生の鋸歯の音程を、楽譜で 8 小節かけて 2 オクターブ上げる |
| 響き(delay) | −10〜−5 | 300〜3000 | 主旋律を付点 8 分のディレイへ送る。戻りは暗く、片側へ |
| 和音・アルペジオ(pad / arp) | −9〜−4 / −10〜−5 | 150〜2000 / 300〜3000 | フィルタで丸め、主旋律より暗く |
| 低音・キック・ノイズ(bass / kick / perc) | −8〜−3 / 0 / −13〜−8 | 60〜600 / 40〜400 / 2500〜10000 | 低音は裏拍 |

発振器の帯域制限(#58)の前後を聞き比べるのに向く: 高い生の鋸歯が前に出て、折り返しの雑音を隠すもの(チップチューンのサンプル&ホールドのような、わざと入れた粗さ)がない。

## 3. このシンセでできないこと(今のモジュールの範囲)
- **ビット数を落とすこと**(値を少ない段数に丸める)。
  - 段数を落とすモジュールはない。チップチューンの粗さは、サンプリング周波数を落として出している。
  - 段数まで落とすには、モジュールを足す必要があり、仕様と決定が要る。
- **深い残響**。リバーブのモジュールはない。ディレイで代わりにしている。
