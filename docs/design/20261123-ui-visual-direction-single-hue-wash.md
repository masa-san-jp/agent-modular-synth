# UI の見た目の方針: 単色ウォッシュ(Single-Hue Wash)

版: 0.4 / 2026-11-24(§10 を追加: 画面に説明文を書かない。0.3 は同日(§9 を追加: 画面の並びと、ラックの主役の見直し)。0.2 は同日(§8 を追加: オーナーの決定と、実装したもの)。0.1 は 2026-11-23: Issue #31。オーナーがまとめたデザイン資料を、このシンセの画面に当てはめたもの)

出典: オーナーの資料「Single-Hue Wash Method」(非公開のページ。Richard Devine 氏が X に出したモジュラーシンセの動画 23 件から、色と動きを測ったもの)。
**元の画像・動画は第三者の著作物なので、このリポジトリには入れない。** ここに書くのは、資料が測った数値と、そこから決めた手順だけ。

## 1. 資料の要点
資料は「観察(測った値)」と「推測(そう見える理由の読み)」を分けている。ここでも分ける。

### 観察(23 件の実測)
| 項目 | 値 |
|---|---|
| 明るさ(相対輝度 L の平均) | 中央値 0.226(0.133〜0.378) |
| 暗部(L < 0.15)の割合 | 中央値 35.9%(9.7〜65.7%) |
| 白飛び(L > 0.8)の割合 | 中央値 0.5%、最大 2.4% |
| 彩度の高い画素(S > 0.5)の割合 | 中央値 87.2% |
| 色相の幅 | 単色の回(14 件)は 1〜31°。多色の回(9 件)は 40〜206° |
| 単色の回の色相 | シアン〜ティール 173〜207°(7 件)、緑 117°・141°、青 227°、紫 268°、マゼンタ 297°、赤 345〜348°。黄・橙は 0 件 |
| 動き | カメラは固定。隣り合うフレームの差は中央値 1.93/255。明滅の周期は 1.0 秒・0.5 秒・0.2 秒付近 |
| 文字 | 画面に文字を重ねた回は 0 件 |

### 推測(資料の読み)
1. 1 色に染めると、多数のケーブルとつまみが 1 枚の模様になり、情報は形と明るさの差だけで読まれる。
2. 画面の約 36% が暗部なので、彩度の高い色でもうるさくならない(暗さが余白の役)。
3. いちばん明るいのは LED と LCD の点だけ。面は明るくしない。
4. 統一感は色ではなく「暗い地 + 発光する点 + 密なケーブル」で保つ。
5. 動くのは光だけ。視線は動く点に集まる。

## 2. 色(資料のシアンの回の実測値。H だけ差し替える)
| 名前 | 値 | 役割 | このシンセでの使い道 |
|---|---|---|---|
| `--wash-0` | `hsl(H 84% 5%)` `#020f17` | 地(面積 25〜40%) | ページの地、ラックの隙間 |
| `--wash-1` | `hsl(H 83% 14%)` `#062e41` | 影 | モジュールの板の面 |
| `--wash-2` | `hsl(H 83% 25%)` `#0b5574` | 面・枠 | 板の枠、つまみの輪郭、区切り線 |
| `--wash-3` | `hsl(H 83% 36%)` `#0f80a7` | 線 | ケーブル、ふつうの文字より暗い補助の線 |
| `--wash-4` | `hsl(H 83% 48%)` `#15c5df` | 発光 | 強調するケーブル(4 本に 1 本)、LCD の面、選択中 |
| `--led` | `#eaffff`(L 0.8 以上) | 点 | LED。合計の面積は画面の 0.5%、多くても 2.4% |

H の候補(実測): 117 / 141(緑)、173〜207(シアン)、227(青)、268(紫)、297(マゼンタ)、345〜348(赤)。黄・橙は使わない。

## 3. 部品
| 部品 | 資料の値 | このシンセでの意味 |
|---|---|---|
| モジュールの板 | 縦長、角丸 0〜2px、枠 1px、板の間 2〜4px | パッチのモジュール 1 つ = 板 1 枚。横に並べる |
| ジャック | 直径 5〜9px の穴、6〜12px 間隔 | 入力・出力のポート |
| ケーブル | 幅 1〜2px、垂れた曲線 | パッチのケーブル。出力ジャックから入力ジャックへ |
| LED | 直径 4〜8px、ぼかし 8〜24px | 信号やゲートの状態(その場の値で点く) |
| LCD | 1 画面に 1 枚、8px 格子、外光 24px | 主役の表示 1 つ(スコープの波形、または演奏の状態) |
| ラベル | 等幅、10〜12px、大文字、字間 0.1em。端の帯にまとめる | 状態の帯(音声、リビジョン、演奏、音量) |
| 動き | 0.2 / 0.5 / 1.0 秒の階段状の明滅。全体は動かさない | LED と波形だけが動く。画面の移動・拡大のアニメーションはしない |

## 4. 組み方の手順(資料の 8 手順を、この画面に当てはめる)
1. 色相 H を 1 つ決める。
2. 地を `--wash-0` で塗り、中央下寄りに `--wash-2` → `--wash-0` の放射グラデーションを置く(周辺の 30〜40% が暗部)。
3. パッチのモジュールを、縦長の板として横に詰めて並べる。
4. 板にジャックを置き、ケーブルを垂れた曲線で結ぶ(`--wash-3`、4 本に 1 本を `--wash-4`)。
5. 主役の表示を 1 つだけ LCD に入れる。
6. 状態を持つ箇所に LED を置く(合計 0.5%、多くても 2.4%)。
7. ラベルは等幅の小さな文字で、上か下の帯にまとめる。
8. 動かすのは LED と波形だけ。

## 5. やってはいけないこと(資料より)
- 単色の画面に 2 つ目の色相を入れる(色相の幅が 31° を超える)。
- 面を明るくする(L > 0.8 の画素を 2.4% より多くする)。
- 暗部を 10% 未満にする。
- 大見出しを絵の上に重ねる。
- 画面全体を動かす(パン・ズーム)。
- 黄・橙を主色相にする。
- 角丸 8px 以上の柔らかいカードや影。

## 6. 資料とこの製品の要求がぶつかる点(決めが要る)
資料は「眺める映像」を測ったもので、このシンセの画面は「操作する道具」でもある。次の点は、資料のとおりにすると要求を満たせない。

| 点 | 資料 | 製品の要求 | 案 |
|---|---|---|---|
| 警告の色 | 単色。2 つ目の色相を入れない | 緊急停止・エラー・音量の上限超えは、見落とせない(REQ-S 系) | 危険の表示だけ、色相を変えずに「点滅 + 文字 + 形(枠の太さ)」で示す。それでも足りなければ、緊急停止だけ例外で赤 |
| 文字の読みやすさ | 文字を絵に重ねない。ラベルは 10〜12px | つまみの値、ポート名、エラー文を読める(REQ-U 系、キーボード・読み上げ) | 文字は `--led` に近い明るさ(地との比 7:1 以上)で、板の中のラベルは 11px 以上。長い文は帯や脇の欄に出す |
| 密度 | 画面を埋める密度 | 20 種のモジュール、最大 256 個。つまみを操作できる大きさ | 板は詰めて並べ、選んだ板だけ脇の欄で大きく操作する |
| 人とエージェントの区別 | 色は 1 つ | 誰の操作かが分かる(REQ-A-006) | 色ではなく、変更の履歴の帯の文字と、変わった箇所の短い明滅で示す |

## 7. 未確認(資料が挙げているもの)
- 他の色相へ移したときに、同じ S・L の値で同じ見え方になるかは、4 色相でしか確かめられていない。
- 資料の再現例の画素は、元と同じ方法では測り直されていない。
- 明滅と音の同期は、音声を解析していないので推測。

## 8. 決定と、実装したもの(DEC-022)
| 項目 | 決定 |
|---|---|
| 範囲 | ラックの表示を足す。編集は、同じ配色のフォームで行う(ラックの上で直接つなぐ・回すのは、後から足せる) |
| 色相 | 人が選ぶ(既定はシアン 196°。候補は §2 の実測値)。**自動**にすると、緑 117° 〜 赤 348° の間を、周期(1 分 / 5 分 / 20 分)で行って戻る。連続に動き、黄・橙は通らない。設定はブラウザに残る |
| 警告 | 緊急停止とエラーだけ、例外で赤(ラックの枠、ボタン、エラーの欄) |
| 誰の操作か | 色相は足さず、形で分ける(エージェント = 塗り、人 = 枠だけ)。変わったモジュールは、ラックの上で 1 秒間、枠が明滅する |

実装:
- `src/view/rack-layout.ts`(配置の計算)、`src/web/rack.ts`(描画)、`src/web/rack-view.ts`(画面へのつなぎ)、`src/view/hue.ts`(色相)、`web/style.css`(配色)。
- LED は、そのモジュールの出力が 0.5 V 以上のときに点く(音声側から、約 50 ms ごとに、その瞬間の出力の大きさを受け取る。1 サンプルごとの処理には何も足していない)。
- LCD は出力モジュールの板に 1 枚。最終出力の大きさの履歴を出す。
- 板が少ないときは大きく描く(高さ 460px まで)。

実測(`npm run test:rack-browser`。資料と同じ測り方。41 モジュールのパッチ、幅 1200px):
| 項目 | 資料の範囲 | この画面のラック |
|---|---|---|
| 暗部(L < 0.15) | 9.7〜65.7%(中央値 35.9%) | 30% |
| 白飛び(L > 0.8) | 最大 2.4% | 0.06% |
| 色相の幅 | 単色は 31° 以内 | 0.0°(自動で動いている間も 31° 以内) |
| 彩度の高い画素 | 中央値 87.2% | 99% |
| 文字と地の明るさの比 | (資料にない。製品の要求) | 本文 14.3:1、補助 8.3:1 |

資料と違う点:
- 測ったのはラックの部分だけ。ページの下のフォームは、資料の密度にはなっていない(操作のための余白がある)。
- 板の上に、モジュールの名前を小さく出している(資料は、絵に文字を重ねない)。どの板が何かを知る手段が要るため。
- ジャックの間隔は 14px(資料は 6〜12px)。板を見分けられる大きさを優先した。

## 9. 画面の並びと、ラックの主役(オーナーの指示、2026-11-24)
§8 の実装を見たオーナーの指示で、次のように改めた。§8 と食い違う点は、こちらが優先。

| 指示 | 対応 |
|---|---|
| マスター音量は重要 | 画面のいちばん上に置く |
| プロンプトの欄は重要。説明は要らない。「prompt」とだけ書く | 音量のすぐ下。ラベルは `prompt` だけ。説明文と入力例は消した |
| 画面の色・緊急停止・MIDI の接続はユーティリティ | いちばん下の「ユーティリティ」にまとめた |
| 音名のボタンの並びが何か分からない | 「画面鍵盤(押している間、その音が鳴ります)」と書いて、ユーティリティへ移した |
| ケーブルは装飾。もっと装飾として扱ってよい | 薄く細く描く(文字の下)。ジャックは、板の下の帯に小さな点で並べる |
| ラックの面積を広く取り、各パラメータの値を数字で見せる | 板にすべてのパラメータの名前と値を出す。板の幅は一定(132px)で、列に積んで面を埋める。ページの幅も広げた |

- 配列のパラメータ(`level[1]`〜`level[8]` など)は、名前の行の下に、値を 4 個ずつ横に並べる。
- 楽譜がパラメータを動かしている間は、**音声側のいまの値**を出す(パッチの値は変わらない。演奏が終われば、パッチの値に戻る)。動いている値は、明暗を反転させて示す。
- 板の面は明るく(資料の「面」の明るさ)、数字は暗い色で書く。
- 緊急停止のボタンが下へ移ったので、**Esc キー**でも緊急停止できるようにした(REQ-S-002: 即時に実行できる)。
- 状態の説明文(「音声は始まっていません。…」など)は、短い語(停止中 / 動作中 / 演奏していません)に縮めた。

実測(`npm run test:rack-browser`。41 モジュール、幅 1200px): 暗部 51%、白飛び 0.02%、色相の幅 0.0°、彩度の高い画素 100%。ラックの大きさは 1166×726px(§8 のときは 1118×299px)。

## 9.1 人が操作する画面 `PANEL`(オーナーの決定、2026-11-27。Issue #59、DEC-029)
ページの上のタブ(`RACK` / `PANEL`)で切り替える。タブは見出しと同じ行に置き、ラックの位置を下げない。`RACK` は §8・§9 のまま。`PANEL` は同じ部品を、人が触りやすい順に並べ替えて見せる(`body[data-view="panel"]`、web/style.css)。

| 順 | 欄 | 中身 |
|---|---|---|
| 1 | マスター音量 | 音量、`START`(演奏への指示と演奏の状態は出さない) |
| 2 | `PANEL` の帯 | `PANIC`(赤)、`RELEASE`、`UNDO`、`REDO`、`FILL` |
| 3 | `CABLES` | 出力と入力のプルダウン、`CONNECT`、ケーブルごとの `DEL` |
| 4 | `MODULES` | 今のパッチの全モジュールのつまみ。追加の欄とモジュールの `DEL` は出さない |
| 5 | `UTILITY` | 計器、MIDI、画面鍵盤、色(緊急停止はタブの下の帯にあるので、ここでは出さない) |

- ラック、演奏データ、パッチの保存・読込、変更の履歴は出さない。
- `FILL` は、ない種類を 1 台ずつ配線なしで足す。全種類がそろっていれば押せない。
- 楽譜が動かしているパラメータは、つまみと数値に音声側のいまの値を出し、数値の欄を `--led` の縁と文字にする(ラックの板の反転表示と同じ意味。色相は足さない)。

## 10. 画面に文章を書かない(オーナーの指示、2026-11-24。DEC-023)
**モジュラーシンセのパネルに文章は書いていない。この画面も同じにする。** 書くのは、短いラベルと値だけ。今後、画面に文字を足すときもこの規則に従う。

- ラベルは、パネルの印字と同じ短い語(`LEVEL`、`START`、`PROMPT`、`SEND`、`STOP`、`PANIC`、`RELEASE`、`UNDO`、`SAVE`、`ADD`、`CONNECT`、`HUE`)。等幅・大文字。括弧書き、入力例、「〜できます」「〜してください」は書かない。
- 状態は文で書かない。印と数字で示す(音声 `off` / `run` / `hold` / `panic`、演奏 `▶ 0:52 / 1:16  +8.1s`、音量 `-8 dB`、反映済みの prompt は `✓`、MIDI は機器の名前か `off`)。
- 「〜していません」「〜されました」のように、状態や結果を文で言い直さない。何も起きていないときは、何も書かない。
- 結果の知らせも短く(`SAVED bass-01`、`LOADED bass-01`)。確かめるときは `DELETE bass-01 ?`。
- 変更の履歴は、記号と値(`+ vco1 MOD-OSC-001`、`vcf1.cutoff = 2`、`vco1.saw → vcf1.in`)。誰の操作かは `AGENT` / `HUMAN`。
- 補足が要るときは、ボタンの `title`(マウスを載せると出る)か、手順書(`docs/`、README)に書く。
- エラーも文で書かない。エラーの ID とコード(`ERR-123 param_out_of_range`)や短い語(`OTHER TAB`、`AUTOSAVE FAILED`、`AUDIO STOPPED`)だけを出す。説明の文は `title`(マウスを載せると出る)に入れる。例外はない。
- ヘッドホンの注意文は、画面から外して README に書いた(以前の決定「音声開始の画面に注意文を表示する」を改めた。DEC-023)。起動時の低い音量・リミッター・緊急停止は、そのまま。
- モジュールの欄の見出しは、板の印字と同じく名前(ID の大文字)だけ。種別の日本語名と、パラメータの単位は、マウスを載せると出る。追加の一覧は種別の番号(`OSC-001`)。
- 列挙型の値の名前は、画面用の短い語に替えて出す(`LIN` / `EXP`、`SOFT` / `HARD` / `FOLD`、`FREE` / `RISE` / `FALL`。対応は `src/view/labels.ts`。仕様の名前は変えない)。
- **自動の確認**: `npm run test:rack-browser` が、全 20 種のモジュール・演奏中・確認・エラーを出した状態で、画面の見える文字(選択肢と入力例を含む)に日本語が 1 文字もないことを確かめる。値の名前の対応が抜けていれば、単体試験が落ちる。

### 実物のパネルの印字(調べた結果、2026-11-24)
製品の手引きと紹介記事の記述から拾った、パネル上の名前。いずれも 1〜2 語で、文・括弧書きの補足・単位の説明はない。
| 製品 | パネルの名前(記述にあったもの) |
|---|---|
| Moog Mother-32 | `FREQUENCY`、`CUTOFF`、`GLIDE`、`TEMPO`、`GATE LENGTH`、`MIXER`、`VCA` |
| Make Noise MATHS | `RISE`、`FALL`、`CYCLE`、`EOR`、`EOC`、`SUM`、`OR`、`INV` |
| Intellijel Metropolis | `PULSE COUNT`、`GATE MODE`(値は `HOLD` / `REPEAT` / `SINGLE` / `REST`)、`STAGES`、`SWING`、`DIV`、`RUN`、`RESET` |
| Mutable Instruments Marbles | `RATE`、`JITTER`、`LENGTH`、`DEJA VU` |
| Doepfer A-155 | `start`、`stop`、`step`、`reset`(`control` の区画) |

- 長さにあたる名前は `LENGTH`、`GATE LENGTH`、`STAGES`。「長さ(分)」のように、単位や説明を括弧で添えた印字は見つからなかった。
- 調べ方の限界: この作業環境からは、製品の手引きの本体とパネルの写真を開けなかった(接続先の制限)。上の表は、検索で得られた手引き・紹介記事の抜粋による。印字の大文字小文字までは確かめていない。
