# 初期版対象・調査方法

調査日: 2026-11-12 / 対応Issue: [#1](https://github.com/masa-san-jp/agent-modular-synth/issues/1)

## 固定対象と結果
今回の初期版は下記の5機種候補と3モジュールに限定する。未取得も調査結果として残し、全製品を網羅したとはしない。

|ID|対象/種別|選定理由|結果|
|---|---|---|---|
|I001|Doepfer A-100 / hardware modular|独立部品の機能分類・現行公開資料|確認範囲を登録|
|I002|0-COAST / semi-modular|ケーブルなしの内部接続と外部パッチの対比|公式概要を登録、PDF取得不能|
|I003|VCV Rack / software modular|仮想信号・時間・保存・APIの具体的記述|確認範囲を登録|
|I004|SYSTEM-500 / hardware modular|SYSTEM-100mの歴史的系譜と現代Eurorackの区別|公式概要のみ登録|
|I005|Buchla Music Easel Modern / 分類保留|東西の異なる設計史を比較する候補|ページ/PDF取得不能、事実登録なし|
|M001|A-110-1 / hardware VCO|発振・波形・normaling・版差|確認範囲を登録|
|M002|A-140-1 / hardware ADSR|時間パラメータ・gate/retrigger|確認範囲を登録|
|M003|VCV Core MIDI-CV / software module|イベントと音高/ゲート変換|確認範囲を登録|

追加・除外: Buchla取得失敗を隠さず維持し、歴史の比較が完全に空欄にならないようRolandの公開概要で補完。ただし歴史的原機の原マニュアルを読めたことにはしない。

## 方法・限界
メーカーのHTML本文を読み、該当節・確認範囲を出典台帳へ記録。PDFリンクを辿ったがBuchlaは422、0-COASTはサイズ制限で未取得。検索スニペットを本文の代わりに事実登録していない。出典は公開情報のみ。転載・コード流用・パネル画像・音源取得・実機試験・ソフト導入は行っていない。

NI Reaktor、Voltage Modular、Moog、詳細なWest Coast方式、ブラウザ固有音声API、フィルタ/VCA/シーケンサーの個別仕様、全モジュール網羅、音質比較、価格/購買調査は今回対象外。初期版の代表性は限定的であり、後段で採用する機能に応じて追加する。

公開文書は無制限のコード/資産再利用許可ではない。ライセンス未確認の素材は採用しない。VCVは公式ライセンス案内のみ確認し、契約全文や各プラグインのライセンスを確認したとはしない。

## 第2回の限定拡充と停止条件（2026-11-12）

代表的な信号処理カテゴリの穴を埋めるため、M004 filter、M005 VCA、M006 sequencerを追加し、いずれも公式本文の確認範囲を登録。Buchla代替調査で取得できた2017 guideをI006/M007として別版登録した。I005 Modernと統合しない。これで13レコード・18出典。全追加対象は処理済み（documented_partial）。

Buchla公式musiceaselページ・QuickStart PDFも422。GitHub Pages版は取得できたが未整備/版不明箇所があり、Modernの数値仕様の代用にしない。S012の過去の取得失敗は保持。S016の公式PDF本文で確認できた限定事項だけを登録した。

停止条件: 初期版に必要な対象状態、構造化事実、出典、比較、未知値、検査・引継ぎが揃ったところで止める。全メーカー/機能の網羅や製品互換レベルの実測は求めない。残る未知値は#2の採用範囲に応じた追加調査に分離する。
